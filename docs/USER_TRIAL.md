# TemperQ 首轮用户试用记录

目标：2–3 位非开发者从 ZIP 下载到首份报告独立完成。先验证安装与拿数据，再记录四阶段是否连贯。本轮不以收益或通过基准为验收条件。

交给试用者：同一份 ZIP、SHA256SUMS 和使用手册。请对方记录卡点；不要索取 token、真实持仓或账号。参与者自行决定是否使用其数据，不需要上传完整数据目录。
