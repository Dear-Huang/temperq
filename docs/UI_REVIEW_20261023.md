## 本轮变化

- 工作台、官网、社区、分享页、浏览器标题及导出文件统一为 WiseHold。
- 安装后可用 `wisehold ui`；旧 `qwb` 命令、Python 模块、目录和卡片字段保持兼容。尚未向 PyPI 发布，请使用源码安装器。
- 训练页保留四步表单，规划模型和可改参数折叠；不改变训练协议和默认策略。
- 模型列表以扣成本结果和证据状态为主，详情保留参考清单、实际账户建议和下载。
- 模拟账户显示权益、首个记录日以来的收益、回撤、费用、净值、持仓、模拟成交及未成交原因。没有记录时不显示虚构曲线或收益；原始持仓未估值时不把现金冒充权益。
- 历史演示、晚到补记、当日前向分别标注；任务受阻和漏记说明继续保留。
- 工作台使用随包字体、图标及字体许可证，运行不依赖 Node 或字体 CDN，支持系统深色模式和手机。

## 已验证与边界

自动测试：此前训练与每日运行 46 项通过；品牌更新后 UI 13 项通过，分享、社区、导出、卡片与账户指标 41 项通过。官网生产构建通过；wheel 内已检查字体、图标、许可证和 `wisehold` 命令入口。仓库发布文件已扫描，无密钥或私有数据误纳入。

浏览器覆盖 1440、390、360 宽，工作台浅色/深色共 8 个页面，官网与社区另行检查；检查页面溢出、字体、模型切换、CSV 下载和历史曲线。官网另检验 3D 像素非空及动画，截图保存在本机 `artifacts/wisehold-ui-qa/`。复验命令：`node scripts/qa_wisehold.mjs`，需要两项本地服务运行及开发环境的 Playwright。

数据与收益边界未因视觉更新而改变：模拟账本仍未含价差和冲击；40 股账户仅为工程历史演示。主力前向账户应从真实每日任务开始积累，不把补齐数据当成前向成绩。原模型页仍读取原研究数据源，账户可单独绑定更新数据源，不能把两者的日期混同。
