## 本轮变化

- 工作台、官网、社区、分享页、浏览器标题及导出文件统一为 TemperQ。
- 安装后可用 `temperq ui`；旧 `qwb` 命令、Python 模块、目录和卡片字段保持兼容。尚未向 PyPI 发布，请使用源码安装器。
- 训练页保留四步表单，规划模型和可改参数折叠；不改变训练协议和默认策略。
- 主导航按“训练 → 评价 → 纸面交易 → 模拟持仓”排列，实验记录和外部体检为次级入口。
- 已训练模型进入同一详情页：跑基准、调参完整重训、可恢复删除；原版本和绑定账户保留。不会把完整重训称为断点续训或增量微调。
- 评价后创建虚拟现金账户。报告提示“可进入纸面验证”或“证据不足”，不宣称可实盘盈利。纸面结果页连接真实现金/持仓预览，沿用账户冻结模型及行情，不修改账本。
- 每个账户可开启本地每日 17:30 后自动检查一次，保存尝试记录；工作台关闭时不执行，数据缺失时不造账。既有全市场 API 调度继续保留。
- 模拟账户显示权益、首个记录日以来的收益、回撤、费用、净值、持仓、模拟成交及未成交原因。没有记录时不显示虚构曲线或收益；原始持仓未估值时不把现金冒充权益。
- 历史演示、晚到补记、当日前向分别标注；任务受阻和漏记说明继续保留。
- 工作台使用随包字体、图标及字体许可证，运行不依赖 Node 或字体 CDN，支持系统深色模式和手机。

## 已验证与边界

软件检查、安装及发布核对统一记录在 [发布复盘](RELEASE_READINESS_20261023.md)。官网生产构建通过；仓库发布文件扫描未发现密钥或私有数据误纳入。

浏览器覆盖 1440、390、360 宽，工作台浅色/深色共 11 个页面，加官网和社区合计 72 张整页截图；检查页面溢出、字体、模型切换、CSV 下载和历史曲线。官网另检验 3D 像素非空及动画，截图保存在本机 `artifacts/temperq-ui-qa/`。复验命令：`node scripts/qa_temperq.mjs`，需要两项本地服务运行及开发环境的 Playwright。

实际网页流程另见 `scripts/qa_workflow.mjs`：40 股真实模型提交独立基准，报告为“证据不足”，可以继续纸面观察；主力前向账户进入真实持仓表单，使用全市场行情生成并导出参考建议。结果保存在本机 `artifacts/temperq-workflow-qa/`，不把这些操作计作收益证据。

数据与收益边界未因视觉更新而改变：模拟账本仍未含价差和冲击；40 股账户仅为工程历史演示。主力前向账户应从真实每日任务开始积累，不把补齐数据当成前向成绩。原模型页仍读取原研究数据源，账户可单独绑定更新数据源，不能把两者的日期混同。
