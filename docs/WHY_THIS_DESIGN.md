# 为什么 TemperQ 这样设计

TemperQ 把一个策略分成三层：**信号**（给股票排名）、**治理**（拿到排名后怎么建仓、何时调、控制多少风险）、**账本**（按 A 股规则成交和记账）。

常有人问：现在不是有"端到端"模型了吗？为什么不让一个网络直接从行情吐出持仓，而要分层？

简短回答：我们做过端到端的研究，也测过它能多赚多少。在我们能拿到的数据和设置下，增益很小，且大部分可以用更简单、更透明的方法拿到。所以产品里兑现的是**能被证据支撑的端到端**，把还没被证明的部分放在研究模式里。

本文说明每个设计选择背后的依据。数字来自作者的内部研究记录，适用范围在每条后面写明。

## 1. "端到端"其实是两件事

| | 含义 | TemperQ 里对应 |
| --- | --- | --- |
| 输入端 | 不用人工设计因子，直接从原始行情学习 | B1：原始 OHLCV 窗口 → GRU |
| 输出端 | 不经人定的组合规则，模型直接输出持仓，用扣成本后的账户收益训练 | B2：可微组合层 + 净效用损失（研究模式） |

很多讨论把两件事混在一起。"不用挖因子"只需要输入端；"比传统方法赚得多"是对输出端的主张。两者证据完全不同，我们分开处理。

## 2. 我们测过的结果

### 2.1 按决策损失训练，增益多数来自更好的预测加权

在半合成的组合任务上（已知真值，便于测"遗憾"即离最优组合有多远），比较三种训练方式：

| 方法 | 开发期遗憾（bp/月） |
| --- | --- |
| MSE：先预测、再优化 | 109.5 |
| PGLS：按投影逆协方差加权的闭式回归 | 95.4 |
| DFL：按决策损失端到端训练（从 PGLS 初始化） | 95.1 |

DFL 相对 MSE 只消除了约 13% 的遗憾，低于事先登记的 1/3 投入门槛；而其中几乎全部增益，一个闭式的加权回归（PGLS）已经拿到，DFL 再微调只多 0.35 bp/月。

背后有一个可以写出来的原因：在线性预测、组合层只有等式约束的情况下，端到端训练的一阶条件恰好就是 GLS 的正规方程，二者的最优系数逐位相同。也就是说，在这类问题里，"端到端"和"预测 + 恰当的风险加权"是同一件事；PGLS 用闭式解直接到达，DFL 靠迭代逼近，迭代不充分只会落后。

适用范围：半合成任务、8 个训练月、含不等式与交易折点的完整问题不满足上述等价条件。这不是"DFL 无效"的结论，而是"在这个设定下不值得为它付出额外复杂度"。

### 2.2 模型不同，不等于组合更好

在 A 股与美股上，扣除随机种子噪声后，动量、树模型、神经网络的选股可以近似互换（相关 0.95–0.97）。同一网络只换种子，组合仍会换掉一部分持仓；集成多个模型的增益仅 0.4–2.7 bp。

模型多样性的经济扩展中，六项主要比较里没有一项同时满足正增益、置信区间排除零和多重检验校正（0/6）。

含义：在预测层换更复杂的模型，换来的主要是持仓的随机变化，而不是可测的收益。

### 2.3 联合训练"从实际成交出发"的版本，暂不成立

候选问题：部分订单未成交时，从实际持仓、可用现金和剩余风险重新决策，并联合训练信号与多期交易策略，能否提高可实现净收益？

立题评估结论为暂不推进：方法描述未超出已有的动态交易与可训练凸优化研究（如 Gârleanu & Pedersen 2013；Boyd 等 2017；JKMP 的 *Machine Learning and the Implementable Efficient Frontier*），手头数据也不足以检验反事实成交。这关闭的是这个具体入口，不是"让学习目标与可交易净收益一致"这个长期问题。

### 2.4 收益差本身就难测

A 股日频收益噪声大。以我们默认的 LightGBM 为例，全 A 5 日排序 RankIC 约 +0.11（t≈8.7），但扣成本后的年化净超额 t 值约 0.3。在两年的检验期上，单个策略相对等权基准的净超额，最小可检测效应约为每年 24 个百分点。

这个数字针对的是"单个策略对基准"。比较两个版本时，配对差的波动通常更小，检测门槛要按那次比较单独测算，不能直接套用 24 个百分点。

含义：仅凭几年的净收益，很难证明"新方法多赚几个点"；比较版本时，应优先看配对的预测指标和可复算的费用、换手，而不是只看收益。

### 2.5 日频真实数据对照：尚未排除简单降换手的解释

2026-10-26，在按代码哈希选取的 240 股票开发子集上，使用 2021–2023 三个滚动折和三个种子比较树模型、多期限树、小 MLP、跨股票网络及净效用微调。这里的 B0–B5 是该次实验编号，与 §1 的 B1/B2 产品引擎编号不同。

跨股票结构、净效用微调都没有得到可确认的增量。普通 MLP 对树模型的年化效用点差约 +8.70 个百分点，主分析校正区间约 [-10.49, +34.23]；不能把点估计领先写成训练方法通过。

神经网络日均单边换手约 8.16%，树基准约 13.48%。复用保存的预测，仅对树排名做因果平滑，把换手事后匹配到 8.17% 后，树的研究近似净年化约为 10.28%，MLP 为 6.46%；MLP 对匹配树的效用点差变为 -1.25 个百分点，条件于匹配的校正区间仍为 [-16.77, +17.97]。这说明初始净优势没有在简单治理对照下保留，不证明全部差异仅来自手续费，也不证明两者等效。匹配系数使用了整段历史换手，不能直接作为产品默认值。

成本拆解也没有支持“成本感知组合必然更好”：原研究组同时改变了成本惩罚和 softmax 权重。保留等权仅加惩罚的近似净年化约为 2.34%，无惩罚仅改 softmax 约为 -2.22%。逐笔现金流没有重复收费，分数也先校准到收益单位；但研究头存在税率常量、意向持仓替代实际持仓、权重集中等偏差，不把它当成合格的账户成本优化器。

这些都是已见开发历史和分数复权单位账本上的结果，未完成整手、最低佣金与公司行动的经济认证。本轮停止追加训练，回到 1.0；不打开 2026 封存行情、不升级 MLP 默认模型。公司行动在纸面日更链路贯通及恢复验收是发布硬项。详见[训练结果](research/TRAINING_COMPARISON_RESULTS_20261026.md)、[两个收口诊断](research/TRAINING_DIAGNOSTICS_20261026.md)。

## 3. 由此得出的设计

| 选择 | 理由 |
| --- | --- |
| 信号与治理分层 | 预测层的差异多数是噪声（§2.2）；治理层的差异落在费用、换手、持仓上，可以在固定路径上逐笔复算。业界也普遍这样分层（QuantConnect/LEAN 的 Alpha、组合构建、风险、执行；Qlib 从预测到 TopkDropout 等策略）。这是成熟架构，不是我们的发明 |
| B1：不用挖因子 | 输入端的端到端是可兑现的：用户只提供日线行情，模型自己学习表示。这是对外的主要卖点之一 |
| B2 放在研究模式 | 输出端的端到端有扎实理论，但在我们的设定下增益小且难测（§2.1、§2.4），默认上线会给用户错误预期 |
| 治理先用成熟方法 | 持仓数、单票上限、排名免交易带、波动目标、EWMA 风险基线都是公认做法。第一个学习组件是风险预测头，必须和 EWMA 对照，并补一组相同平均仓位的固定规则，防止把"多拿现金"误认成模型能力 |
| 默认值都有出处 | 用户不调参也能得到有依据的配置；改过的参数在报告首页列出 |
| 成绩卡不打分，只给四种灯 | 多数策略会是"还不能下结论"（§2.4）。如实给出黄灯，比给一个看似精确的分数更有用 |
| 只认前向记录 | 历史回放可以被调出来；只有上线后的纸面账本才是最终成绩 |
| 账本规则锁定 | T+1、申报数量、最低佣金、印花税、涨跌停、时点契约一改，结果就会失真，所以只显示不开放 |

## 4. 我们会怎么说，不会怎么说

| 会说 | 不会说 |
| --- | --- |
| 不需要你设计因子，导入日线就能训练 | 端到端比传统方法赚得多 |
| 模型可以相似，政策因人而异 | 我们的模型更强 |
| 历史检验说明的是：在给定数据和假设下得到了什么 | 回测证明这个策略能赚钱 |
| 这一步用的是成熟方法 | 这是独创算法 |

## 5. 什么情况下我们会改变判断

- B2 在真实数据上、相同信号与授权下，对 PGLS 类强基线和纯规则治理，在前向记录中持续给出超出随机波动的净收益增量。
- 出现含不等式约束、交易折点的设定，在其中 DFL 与 PGLS 的差距随训练长度明显扩大。
- 用户的真实账户数据显示，某类治理决策在多个账户上一致改善费用或风险，而不仅是降低仓位。

在这些证据出现之前，端到端的输出端继续作为研究模式提供。B2 的代码、设计记录和合成数据验证在本仓库中（见 [训练说明](UTILITY_TRAINING.md)）；§2 引用的 DFL/PGLS 与模型同质化实验目前是作者的内部研究记录，整理后另行公开。
