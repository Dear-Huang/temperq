# 策略审计：通用导入格式

TemperQ 不运行你的策略代码，只审计回测的**输出**。任何平台、任何语言写的策略，只要能导出下面几个文件，就可以审计。

BigQuant、聚宽、米筐的原始导出可以直接上传，平台会自动识别；其他平台按本文的格式整理即可。

## 1. 要交哪些文件

| 文件 | 要求 | 用来审什么 |
| --- | --- | --- |
| `trades.csv` 逐笔成交 | **必需** | 费用复算、买卖价差、最低佣金、持有期、成交可行性 |
| 策略代码（`.py` 或 `.txt`） | **必需** | 读出参数，对照意图与执行；能解析的平台可生成优化代码 |
| `holdings.csv` 每日持仓 | 推荐 | 回撤、逐股盈亏归因闭合 |
| `account.csv` 每日权益与现金 | 推荐 | 精确的账户路径与回撤 |
| `logs.csv` 运行日志 | 选填 | 受阻成交、数量调整、公司行动 |
| `scores.csv` 每日打分 | 选填 | 信号能管几天、换构建方式的对比 |

只有持仓、没有逐笔成交时，平台会由持仓变化反推交易，报告标明"由持仓推算"，费用与价差相关结论会弱很多。

文件编码 UTF-8 或 GBK 均可；第一行是表头；日期一律写 `YYYY-MM-DD`。

## 2. 字段

### trades.csv（逐笔成交）

```
date,time,code,side,quantity,price,fee,order_id
2024-01-02,09:30:00,600000.SH,buy,1000,10.00,5.00,1
2024-01-03,09:30:00,600000.SH,sell,1000,11.00,10.50,3
```

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| `date` | 是 | 成交日期 |
| `code` | 是 | 股票代码，`600000.SH`、`600000.XSHG`、`SH600000` 均可 |
| `side` | 是 | `buy`/`sell`，或 `买入`/`卖出` |
| `quantity` | 是 | 成交股数，正整数 |
| `price` | 是 | 成交价，**建议用不复权的真实价格** |
| `fee` | 是 | 这笔成交实际扣的费用（佣金＋印花税等），不知道填 0 并在页面说明 |
| `time` | 否 | 成交时间 `HH:MM:SS`，用于判断开盘/收盘集合竞价 |
| `order_id` | 否 | 委托编号；同一委托多笔成交时用来合并核对最低佣金 |

### holdings.csv（每日持仓）

```
date,code,quantity,price
2024-01-02,600000.SH,1000,10.00
```

每个交易日收盘后的持仓，一只股票一行；`price` 为当日收盘价（可选）。

### account.csv（每日权益与现金）

```
date,equity,cash
2024-01-02,99990.00,79990.00
```

### scores.csv（每日打分，选填）

```
date,code,score,available_at
2024-01-02,600000.SH,0.83,2024-01-02T08:30:00+08:00
```

要覆盖**每日全部候选股票**，不只填最终买入的那几只；`available_at` 是这份打分当时实际可用的时间。

## 3. 各平台怎么导出

| 平台 | 方法 | 状态 |
| --- | --- | --- |
| BigQuant | 回测结果页导出「交易」「持仓」「日志」，加策略代码，原样上传 | 已用真实导出验证 |
| 聚宽 | 回测页导出「交易详情」「持仓」，加策略代码，原样上传；分红送转由账户推断。备用：研究环境运行 [导出脚本](../src/qwb/static/joinquant_export.py) | 原始导出已用真实回测验证；导出脚本待真实账号验证 |
| 米筐 | 回测页导出「交易详情」「持仓详情」「账户详情」，加策略代码，原样上传；分红送转由账户推断 | 已用真实导出验证 |
| 掘金、QMT、PTrade 等 | 按本文格式自行整理 | 暂无专用适配，有用户需要时补 |
| 文华、TB、通达信等公式语言平台 | 按本文格式自行整理；代码只存档，不解析 | 只给文字建议 |

## 4. 各平台能拿到什么

| 平台 | 费用与价差审计 | 盈亏归因 | 参数核对 | 生成优化代码 |
| --- | --- | --- | --- | --- |
| BigQuant | 能 | 能 | 能 | 能 |
| 聚宽 | 能（需逐笔成交） | 能 | 能 | 暂不提供，先给文字建议 |
| 米筐 | 能（需逐笔成交） | 能 | 部分 | 暂不提供，先给文字建议 |
| 其他 Python 平台 | 能 | 能 | 部分（只读取明显的参数） | 不提供 |
| 公式语言平台 | 能 | 能 | 不提供 | 不提供 |

"能"指在材料齐全时可以出结论；最终结论仍以报告为准。

## 5. 平台会做哪些核对

- **自动识别**：BigQuant、聚宽、米筐原表、本文格式。遇到不认识的表头会直接报错，不会猜着读。
- **一致性**：持仓的逐日变化是否等于成交；成交、持仓、权益能否闭合；代码里的回测区间与文件实际区间是否一致。
- **分红送转**：聚宽、米筐不导出公司行动。平台从"无成交却多出的现金"识别现金分红（按前一日市值分摊），从"无成交、股数按整档比例增加且股价下跌"识别送转，列为推断项请你确认。
- **同一次回测**：平台只能交叉核对、不能证明文件来自同一次回测，需要你在导入时确认。

## 6. 隐私与安全

- 代码只读解析，**从不执行**。
- 所有文件只保存在你自己的电脑上，不上传到任何服务器。
