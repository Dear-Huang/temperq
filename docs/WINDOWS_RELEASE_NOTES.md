# TemperQ Windows 便携候选版

完整解压 `TemperQ-windows-x64.zip` 后双击 `start.bat`。自带 Python 和 CPU 依赖，无需安装 Python、uv、git 或 Node；无需显卡。推荐 Windows 10/11 x64、16GB 内存。

训练页新增“一键下载免费数据（BaoStock）”：无需账号、token 或积分，默认下载 40 股、自 2021 年到昨天的日线。完成后选“用这份数据继续”，训练得到首份报告，再按“训练 → 评价 → 纸面交易 → 模拟持仓”继续。任务有进度、取消和重试；失败不发布半份快照。

中文及空格目录中的模型保存、读取已修复。内含完整本地引擎源码、组件许可证、文件哈希清单；请对照 `SHA256SUMS.txt` 核验下载。升级前备份自己包内的 `data/` 与 `runs/`。命令行入口为 `temperq.bat`。

开发机已完成中文/空格目录迁移、禁止外网下的启动/CPU 训练，以及联网下载 56,160 条真实日线后出首份报告。联网验收发生过一次服务端网络接收错误，页面重试后成功；不把失败从验收记录中删除。

启动和合成训练可离线，免费行情需要联网，服务可能延迟或中断；失败后可重试。40 股是当前选定的入门样本，不代表历史全市场或策略收益。纸面账本扣佣金与印花税，尚不含价差和冲击；不自动向券商下单，不承诺收益。独立电脑和非开发者试用尚待完成，本版为候选版。

模型、协议或实现升级后，旧冻结账户会停止；已有记录必须保留，需用新账户继续，不会静默拼接不同实现的收益。关闭电脑不会记账；工作台运行和外部计划任务的区别见手册。
