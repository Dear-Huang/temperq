# 审计规则登记表

注册表版本：`audit_rules_v1`。本文件由 `qwb.audit_rules.document()` 生成，请勿手改；改规则时改代码并重新生成，测试会核对两者一致。

每条审计结论都标注它用到的规则编号。三类规则分开：规则事实不可调；有出处的方法写明来源；经验阈值是项目自己的判断，尚未经样本检验，可在审计设置的“判断口径”里调整，报告保存当次使用的值。

## 规则事实

| 编号 | 内容 | 来源 |
| --- | --- | --- |
| F-ACCOUNT | 权益 = 现金 + 持仓市值；持仓变化 = 成交；现金变化 = 成交金额 + 费用 | 账务恒等式 |
| F-TICK-STOCK | 股票最小报价单位 0.01 元 | 沪深交易所交易规则 |
| F-TICK-FUND | ETF、基金、债券最小报价单位 0.001 元 | 沪深交易所交易规则 |
| F-STAMP | 卖出股票按成交日适用税率缴印花税；2023-08-28 起 0.05%，此前 0.1%；基金和债券免征 | 财政部、税务总局公告 |
| F-MIN-COMMISSION | 佣金不足最低佣金时按最低佣金收取 | 券商佣金规则；最低额由合同约定 |

## 有出处的方法

| 编号 | 内容 | 来源 |
| --- | --- | --- |
| M-TICK-HALF | 价差下限 = 每边半个最小价位 | 作者 STRUCT 稿（SSRN，未经同行评审） |
| M-FIFO | 按先进先出配对买卖，计算每笔已平仓交易的持有期和盈亏 | 通用会计配对方法 |
| M-SLIPPAGE | 回测已计的滑点按平台文档换算为每边成本，价差情景只补差额 | 聚宽 set_slippage 文档；RQAlpha 滑点模型文档 |
| M-RANK-IC | 每个调仓日，用全部候选标的的分数与到下一调仓日的收益做秩相关（Spearman IC） | 因子检验常用方法（信息系数） |
| M-PREMISE-POWER | 最小可检测 IC = (显著性 t 门槛 + 0.84) × IC 标准差 / √期数，0.84 对应八成检验力 | 统计检验力的正态近似（单侧） |
| M-RANK-REPLAY | 用策略导出的每日排名回放换仓次数；不重算收益 | 本项目，见 audit_signals |
| M-FILL-TIMING | 固定原成交股数和费用，把成交价换成同日其他分钟的收盘价，比较盈亏；不重跑策略决策 | 本项目，见 audit_timing |

## 证据等级

| 等级 | 含义 |
| --- | --- |
| E1 | 记录事实：导出记录与账务恒等式上的复算 |
| E2 | 描述：事后分组，不证明改了会更好 |
| E3 | 情景：固定原成交，在声明假设下估计 |
| E3c | 条件情景：有前提未确认，结论随它变 |
| E4 | 同区间复跑：同一段历史重跑的比较，仍是样本内 |
| E5 | 独立验证段通过：冻结候选后在未看过的验证段通过 |
| E6 | 前向观察：模拟盘或实盘记录 |
| N | 待补材料：缺少计算所需材料 |
