# 治理实验：同一信号，不同账户政策

当前为 `governance_replay_v1` 本地历史实验。网页导航“治理实验”可选择训练预测集、行情快照、回放日期、初始现金、持仓数、单票上限和继续持有排名，再指定仓位上限、最低现金、目标年化风险和滑点压力。按下运行才记录一次尝试，后台支持取消和重试。

四组对照：

1. 规则基线：相同持仓数，不加排名缓冲或单票截断，固定仓位。
2. 你的规则：排名缓冲和单票截断，固定仓位。
3. 同一规则 + EWMA：用日线平方收益风险估计调整总仓位。
4. 同一规则 + ML：CPU Ridge 预测未来五日风险，使用相同目标风险和仓位限制。

四组采用相同初始现金、五交易日节奏、次日开盘代理及原有股数成交引擎。报告显示历史净值、费用、成交额/权益、回撤、平均仓位、风险目标误差和风险预测损失，决策页显示选股/继续持有/卖出的原因、目标权重及次日成交或受阻情况。不同敞口下收益差不代表 ML alpha，首版不出显著性结论。

## 命令行

```powershell
temperq governance --predictions runs/my_training/predictions.parquet --data-dir data/my_feed --start 2026-09-01 --end 2026-10-22 --n-hold 10 --hold-until-rank 15 --max-weight 0.1 --target-volatility 0.15
```

也支持 CSV，必须包含 `code,decision_time,prediction`；证券代码按原有沪深支持范围验证，时间必须带时区并对应北京时间 15:30。同一证券同一日只能有一个分数；不能用后来生成的信号倒填时间。若有 `data_snapshot_id`，必须与冻结行情一致。工具不独立证明上游训练没有泄漏。

结果默认写入 `runs/governance/<新ID>/`，不会覆盖已有文件。包含 `result.json`、逐组 `path.csv`、`decisions.jsonl`、`fills.jsonl`、`positions.jsonl`、`risk_models.jsonl`，以及 `risk_samples.parquet`。保存配置、信号和数据文件哈希、模型系数、成熟标签截止日及实现身份。失败记录和重试也保留；本地哈希不是独立防篡改证明。

## ML 的范围

Ridge 使用 5/20/60 日的 log 年化均方收益和 20 日 log 下行均方收益，固定 alpha=10。训练标签是当日已知前 N 名等权篮子从次日开盘到第六日开盘的五个复权收益的年化均方。每 21 个交易日重拟合；只用 `label_end < fit_day` 的样本，至少 126 个成熟日期，否则明确回退 EWMA。输出在训练 log 标签范围内裁剪。超参数不在回放测试期搜索。

控制时对实际政策选出的篮子计算风险特征。训练篮子和实际篮子可能不同，风险特征依赖 60 个交易日的完整价格，日线代理不等同高频 realized variance。为公平比较预测质量，EWMA 和 ML 的 QLIKE 都在同日同一前 N 名参考篮子上计算，只计回放截止前成熟标签；重叠标签不能当成独立样本。参考篮子的预测误差与各自账户的实际净收益分别列示。

## 当前边界

- 首轮从现金起步，固定五日节奏；不含止损、行业限制、大盘择时和换手预算。
- 实际股数账本遇到持仓复权因子变化即停止，需后续公司行动数据适配；不忽略分红拆股，也不伪造连续净值。持仓行情缺口或日历不连续同样停止。
- 费用为佣金、最低佣金、印花税及用户给定的滑点压力，尚未标定实际价差/冲击。
- 限制作用于目标。市场波动和成交受阻可能造成实际超限，报告保留记录；风险目标不是亏损保证。
- 本轮未新增前向账户，不修改 `daily_strategy_v1` 或已有纸面账户。前向双账户、社区与元标签分别后续交付。

## 本轮验收（2026-10-23）

使用现有 BaoStock 40 股快照和 B0 逐期预测，回放 2026-10-09 至 2026-10-22，四组共十个收盘状态。后台实验 CPU 耗时约 3.5–5.7 秒（不含浏览器与启动；首次冷启动曾为 17.4 秒），不能外推到全 A 十年。ML 实际使用此前成熟标签拟合，未走样本不足回退。短区间仅验收工程闭环，不构成投资效果判断；40 股引导池也不代表完整市场。

自动化覆盖：18 项治理测试、44 项既有策略/操作/纸面网页/任务测试、22 项主网页与工作流测试。浏览器用真实数据完成表单、后台任务、四组报告和逐日成交，在 1440、768、390 像素宽度检查，无页面横向溢出。证据位于本地 `artifacts/governance-qa/`，不随源代码公开。实际受阻委托与风险漂移保留，不宣称所有目标都能成交。

已检查原有前向账户的冻结实现哈希仍匹配，本轮没有修改其模型、协议或账本。G4 双账户、长期公司行动回放与非开发者独立试用仍未完成。
