# Windows 首次使用试用脚本

供维护者安排 2–3 位独立试用者。此文是待执行脚本，不表示已经邀请或完成试用。建议至少一位不写代码的人和一位用过 Python 量化框架的人。维护者负责邀请与收集反馈；工具不会替你联系他人。

## 提供的材料

Windows 便携 ZIP、SHA256SUMS、本文及 [策略工作区指南](STRATEGY_WORKSPACE.md)。使用新建空文件夹，保留旧数据；不要求上传真实持仓或账户。用户可以用假设资金与空持仓开始。

## 新用户任务

维护者先不演示操作，不代点按钮；卡住时先请用户说出自己以为下一步要做什么，再提供帮助，并记录这次帮助。

1. 解压并双击 `start.bat`，说出工作台第一步让你做什么。
2. 用 BaoStock 准备免费行情。记录下载等待、失败或重试，**下载耗时与实际操作耗时分开**。免费服务不可用时记录失败，不偷偷换成演示数据算完成。
3. 两条路线任选其一：按默认值训练模型；或使用随包的公开日线入门模型，选择匹配的 `free_daily` 行情。入门模型仅覆盖声明的 40 股，不代表全市场。
4. 填假设资金，选政策预设。说出“买多少只、多久调整、成本怎样计入”。把资金改成 500 万，观察默认持仓数变为 30；自己微调后改资金，观察改动是否保留。
5. 跑历史检验。请用户解释“当前政策、立即调整、平均仓位匹配”三组的区别，以及“证据不足”是否等于策略不能运行。不能解释就算需要改进。
6. 开启纸面观察；如没有当日数据，指出等待原因。确认历史成绩没有成为前向成绩。用户自行选择是否开启每日检查，知道关闭应用后自动检查会停止。
7. 次日重新打开，独立找到原策略，说明最新日期、是否受阻、是否有迟到重建。这个任务必须等到次日，不能用历史演示冒充完成。

## 专业用户追加任务

导入自己的五日预测，声明股票池和版本；追加新日期，尝试修改一条旧分数，确认平台拒绝改写。导出规则模板，在新策略中导入，对照实际生效值。查看一笔成交的佣金、印花税、STRUCT 半价差估计及额外压力，指出尚未计入的成本。
