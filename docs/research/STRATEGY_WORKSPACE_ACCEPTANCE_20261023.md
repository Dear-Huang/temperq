## 复现

```powershell
python -m pytest -q
python scripts/run_strategy_demo.py artifacts/strategy-demo-new
node scripts/qa_strategy_workspace.mjs

```

离线脚本只使用合成行情，无网络和私有数据依赖，已加入 Windows/Linux Python CI。输出目录需是新目录，保留此前失败证据。
