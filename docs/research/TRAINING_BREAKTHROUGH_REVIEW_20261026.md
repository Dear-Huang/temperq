# 训练突破候选：多期限、跨股票的端到端组合学习

日期：2026-10-26。性质：研究选题与计算可行性记录，不是已验证的新算法、收益报告或发布 SPEC。

## 1. 判断

最值得投入的一条研究线是：**用本地量价特征和用户因子，学习具有持续性、在真实成本下可以持有的组合；用小型跨股票模型学习相对关系，并让组合的净结果参与训练。**

它改变了训练对象：从逐行预测某只股票未来五日收益，扩展为学习同一时点各股票的相对价值、信息能持续多久，以及在已有持仓上应形成什么组合。模型需要产出选股和配置能力，而不仅是在现成策略外面加交易过滤器。

推荐置信度：**值得做有边界的研究，尚不能判断能否成为本项目的技术突破。** 直接组合学习、跨资产注意力、多期限预测都有先例；把这些模块接起来不自动构成学术创新。候选增量是：在个人电脑预算、A 股长仓及离散交易约束下，是否能比强树模型和成熟组合构建方式稳定获得更多净效用。如果成立，再验证对用户不同因子集的适配，而不是现在宣称通用预训练。

本轮新增一个合成计算探针和这份研究记录。没有改发布范围、普通训练默认、模型权重或用户账户；没有启动真实市场训练、GPU 大规模实验、自动账户或推送。

## 4. 候选路线排序

| 路线 | 能改善的地方 | 成本与主要问题 | 建议 |
| --- | --- | --- | --- |
| 多期限 + 跨股票小网络 + 净效用训练 | 同时探索信息持续性、相对关系与组合目标 | 需要解决梯度与真实执行的偏差；独立日期有限 | 主研究线，拆成可归因实验 |
| 多期限/成本目标的树模型 | 低成本学习持久信号，建立难以战胜的基准 | 自定义组合梯度较难；单纯标签扣一笔费用不是账户目标 | 与主线同时设为强基线和备选成果 |
| TabM、小 MLP、紧凑 TCN 原始序列模型 | 更合适的非线性表示；小网络可用组合损失反传 | 换模型名称不会增加外部信息；低信噪比仍在 | 作为编码器对照，不独立承诺突破 |
| 自动因子挖掘/LLM 因子代理 | 扩展候选表达式和用户想法 | 搜索开销、多重尝试、拥挤竞争；原始数据相同 | 后置，先证明组合学习值得做 |
| Kronos 微调/金融基础模型 | 可能利用外部预训练和序列表示 | 当前本机零样本证据弱；预训练污染、显存与数据范围待核验 | 保留有边界实验，不作为首要投入 |

树模型可先学习未来不同区间的收益或排名，再形成成本感知组合。若尝试直接效用 boosting，需要对分数求梯度，处理跨样本耦合与 Hessian 近似，并用真实账本检查近似目标是否可靠；不能把“支持 custom objective”解释成现有树训练器已经支持任意端到端策略。

## 5. 因子库在这里是什么

有三个不同问题：

1. **行情衍生特征**：均线、波动、反转、量价关系等在本地计算。Alpha158 风格可以作为基准特征体系；不会凭公式数量创造新的外部信息，但能提供归纳偏置。成交量、VWAP 等缺失时必须删除相关公式或明确提供来源，不能拿成交额冒充。
2. **外部信息特征**：用户带来的财务、行业、事件等可能增加独立信息，需保留可用时间、公告日、修订与历史股票池。JKP 特征定义/因子收益不是可直接免费分发的 A 股时点财务面板。
3. **用户自有因子集**：可以作为训练输入，第一阶段按固定列和明确版本重新训练。一个固定列 MLP 并不能理解任意陌生因子的意义；列数可变、列顺序不变性、缺失和符号变化也要单独设计。

真正值得后续研究的是“少量数据适配新因子集”：共享编码器 + 可替换的小适配器，并在完全未参与训练/选择的因子家族或独立信号集上验证迁移。如果只在同一组因子上随机遮掉几列，不能宣称跨用户泛化。首个实验不依赖这个尚未建立的能力，也不收集或上传用户私有因子。

## 6. 首个模型假设

输入为时点 t 可见的因子截面 X_t、历史市场摘要和漂移后的持仓状态。先用共享小编码器处理每只股票，再用少量潜在 token 汇聚全截面信息并返回个股表示，形成股票评分及组合目标。

低秩 token 汇聚是待检验的近似，不是 AIPM 原模型复现。全股票注意力作为较小池研究对照，不能仅凭便宜就认定低秩近似保留了经济价值。第一版固定因子 schema；可变因子接口另设研究阶段。

训练分两步但不改输入或测试集：

1. 使用成熟的多期限标签预训练表示，避免一开始就在稀疏成交和约束边界上寻找梯度。
2. 用多日组合净效用微调，保留适度辅助预测损失和权重变化正则；仅在因果训练/内层验证确定的范围内选择权重。实际选择的应是完整流程，不是测试期最好看的 checkpoint。

多期限初始候选为未来 1–5、6–20、21–60 个交易日的区间收益；也可用累积收益，但不能把 5/20/60 日累积收益直接相加而重复计算。标签统一遵守下一可交易时点的执行语义，训练截止必须考虑最远标签的成熟时间。多头输出是研究候选，不表示现有五日产品闭环已经支持其他期限。

微调目标可写为：

```text
maximize mean(net daily account return)
         - risk_penalty
         - representation_or_prediction_regularization
```

成本由同一账户协议给出。已有持仓和现金进入状态，组合收益由逐日持仓产生；不能把重叠五日标签当每日可收取的利润，也不能给排名分数直接减去若干 bp。风险估计、特征筛选、收益校准、学习率与早停全部只用当时可见的训练/内层验证数据。

真实整手、最低费、涨跌停、T+1 含非光滑机制。可微代理只负责产生候选训练方向；必须先取得适用范围证据，再由独立精确账本评价。原 B2 的梯度和代理资格问题仍开放；本轮探针没有解决它们。预训练、数值尺度校验、较低维策略组合都是可试的学习辅助，不能通过调低真实成本或放宽约束制造效果。

## 7. 本轮计算可行性结果

运行 [合成探针](../../scripts/probe_factor_context.py)：

```powershell
python scripts/probe_factor_context.py --output artifacts/training-breakthrough-20261026/compute-probe.json
```

实际环境为 PyTorch 2.11.0+cpu、2 个 CPU 线程、固定种子；每步 2 个合成截面，2 步预热后测量 5 步。机器显卡为 RTX 5060 Laptop，约 8GB 显存，但这个 Python 环境没有 CUDA；没有进行 GPU 测试。

| 合成场景 | 参数数 | 平均前向+反向+更新 | 总梯度 L2 范围 |
| --- | --- | --- | --- |
| 500 股票 x 32 特征 | 48,897 | 0.0346 秒/步 | 1.67e-4 至 2.44e-4 |
| 5,000 股票 x 158 特征 | 56,961 | 0.1979 秒/步 | 6.23e-5 至 1.30e-4 |

5000 股票、4 头、float32 的单日显式全注意力矩阵约 381.5 MiB；16 token 的两向交叉注意力矩阵合计约 2.44 MiB。这里是矩阵元素数量计算，不是峰值显存实测，也未计激活、梯度、优化器；现代高效注意力实现也不一定显式保存全矩阵。

可得出的结论只有：**这种固定 schema 的小结构在本机 CPU 上可以前向、反向并更新，首批研究不必以大模型和高显存作为前提。** 非零梯度不证明学到了金融信息，更不代表原 B2 的约束求解梯度已修复。

探针使用合成随机数据、稠密 softmax 和光滑比例成本，没有市场数据、严格仓位上限、整手、T+1、受阻交易、跨日状态反馈、完整净效用训练或预测质量检验。它不是可部署模型，不把步耗时外推成整套训练需要几分钟，也不声称“8GB 已验证支持完整训练”。

## 8. 必须战胜的实验对照

第一批只用一个明确的流动股票池、同一数据快照、同一成本/成交协议和固定因子集。先从真实存在的约 32 个紧凑量价特征起步；完整 Alpha158 或用户外部因子另做输入增量，不与架构变化混为一次提升。

| 组 | 模型/目标 | 回答的问题 |
| --- | --- | --- |
| B0 | 严格历史验证选轮数的 LightGBM + 当前可靠组合规则 | 强树基准，不能拿固定 300 轮的弱版本充当对手 |
| B1 | 多期限 LightGBM + 训练期校准 + 成本感知组合 | 多期限本身能否改善？ |
| B2 | 小 MLP，辅助预测目标 | 同输入的小神经网络是否有必要？ |
| B3 | 同小 MLP，净效用微调 | 训练目标能否带来额外净改善？ |
| B4 | 加跨股票上下文，辅助预测目标 | 股票关系是否提供增量预测信息？ |
| B5 | 同跨股票模型，净效用微调 | 上下文与组合目标是否互补？ |

B2–B5 是结构 x 目标的 2x2；各组模型容量、选择机会、日期和数据处理尽量对齐，记录实际资源差异。TabM 可以替换/增加为一个预先登记的编码器对照，但不在看过外层结果后无限追加方法。B0/B1 必须获得合理且可比的调参预算。

预先计算的市场广度、因子分布等固定上下文摘要对所有组开放；保留树模型/MLP 加固定汇聚摘要的对照。否则神经网络独占额外市场输入，不能把胜出归因于注意力结构。动态股票池、缺失数据和停牌掩码也必须一致。

初始资源安排是建议上限，尚未启动：

- 阶段 A：最多 2 CPU 小时，做一个开发折的小池梯度、敏感度、代理/精确账户诊断。缺关键字段或执行资格就先定位，不继续大规模拟合。
- 阶段 B：完成 A 后冻结配方，最多 24 CPU 小时；如另建 CUDA 环境，则改为最多 12 GPU 小时的备选预算，两者不自动累加。比较 3 个时间顺序开发折、3 个种子；先实测单折耗时，预算内无法完成则如实记录未运行，不降验收门槛。
- 阶段 C：开发证据成立后再决定全市场、更多时期及新因子适配，不把这些预算提前承诺为本轮已授权运行。

## 9. 继续与停止条件

预先确定一个主经济指标：**固定风险惩罚下、扣全部声明成本后的日度效用差**。日均效用计算和风险惩罚参数在训练/内层验证确定，不在外层调整。配对日期块推断覆盖序列相关；另报净收益、回撤、仓位、换手、成本和可交易覆盖。数千只股票、不同 seed 不能充当独立市场日期。

继续投入条件：

1. 训练参数确实改变了可执行动作；代理改善与精确结果变化有可解释的对应关系，没有靠持有更多现金、减少覆盖或放宽规则获得表面优势。
2. 相对 B0/B1 强基线的主效用差在预先冻结的开发检验中有支持，并且不是由单折/单种子驱动；简单成本压力下方向稳定。只有净效用提升才声称经济改善，只有 IC 提升时只声称预测改善。
3. 结构消融有增量。B5 只胜过 B0、却不胜 B1/B3 时，应采用更简单的有效方案，不能宣称跨股票模型突破。

停止或转向条件：梯度/动作长期不敏感；只改善连续代理；净改善完全由更低风险暴露解释；只在事后挑选的时期有效；或预算用尽仍无法区分。区间宽应写“尚不能裁决”，不是证实无效。

2024–2025 以及已有反复研究的 2021–2023 都不能重新包装成未见测试。历史滚动折提供开发证据，最终需要核查确实未用于模型选择的新时间段，或在冻结方案后积累新的前向预测记录。模拟调试数据也不能充当独立确认。

跨因子集适配进入下一阶段的条件是：先证明同数据下组合学习的增量，再在独立保留的因子家族/信号来源上证明适配收益和训练成本；不以复制列、改名称或随机 mask 代替迁移验证。

## 10. 对产品增量的诚实表述

若研究成功，可交付的是一个本地训练器：用户提供可追溯的数据和因子，训练器学习信号的持续性、股票之间的相对关系及可执行组合，并导出与基准同尺度的证据。小白可以用本地量价特征起步，专业用户可以替换输入；是否真正适配不同用户要另有证据。

在取得上述证据前，不能使用“全新范式已经成立”“原始 CSV 自动产出可盈利模型”“超越聚宽/BigQuant”或“无需数据因子”之类宣传。当前最值得做的是这项具体研究，而不是继续扩展页面和模块来代替训练进展。
