# 阶段 A 首轮结果与可复用工程

日期：2026-10-26。依据：[研究设计](TRAINING_BREAKTHROUGH_REVIEW_20261026.md)。状态：**前置检查及首轮诊断已执行；B3/B5 不放行，阶段 B 未启动。** 真实市场下的端到端执行代理与 STRUCT 训练资格仍未取得。

## 1. 本轮交付什么

首个可复用产出是 [多期限信号诊断脚本](../../scripts/analyze_signal_horizons.py)，不是一个已经胜出的新模型。它可以消费平台保存的预测；其中的 `analyze()` 接受对齐后的信号矩阵，可供后续导入信号页面复用。

- 同一批信号在 1、5、10、20 个交易日的累计 RankIC。
- 分段的第 1 天、第 2–5 天、第 6–10 天、第 11–20 天 RankIC，避免把最初几天的收益误认为持续二十天。
- 各期限自身可用样本与全部期限共同样本，逐年诊断、有效日期和带时间相关修正的区间。
- `report.json`、`summary.csv` 和 `daily_ic.csv`，可接入现有模型成绩卡和曲线组件；没有新增普通用户页面或改变默认模型。
- 明确下一交易日开盘入场、到期退出、复权处理和标签成熟截止；读取前先检查文件日期边界，研究命令拒绝 2023 年之后的数据。

样本外身份仍须由上游训练记录证明，单靠传入预测文件不能认证无泄漏。脚本不输出个股“还能涨多少天”、预期收益、成本覆盖概率或买卖建议。

另有两项研究工具：[检验能力与日期用途审计](../../scripts/audit_training_stage_a.py)、[梯度及精确账户诊断](../../scripts/diagnose_training_stage_a.py)。均不操作用户账户。

## 2. 数据与留出期

找到 E 盘原始历史快照的 2018–2025 年分区。本轮只打开 2021–2023 年价格，用既有历史验证选轮数模型的 137,122 条样本外预测，覆盖 233 个实际出过信号的代码。暂不需要 API 补取。

与原开发样本共同记录的开盘价和复权因子逐项比较，最大绝对差均为零。这个核对不等于全部输入或时点数据资格认证；开发样本中未出过信号的代码不在本轮范围。

**2026 年不能认证为整段干净留出期。** 已有文档明确记录：10 月 12–22 日曾进行 API 模型账户回放；策略页面另用过 10 月 9–22 日进行检验。软件用途也可能暴露模型效果，不能重新称为从未查看。

本轮只审查日期、用途元数据和文件哈希，没有读取 2026 年预测/收益/绩效行。扫描 1,548 个本地候选文件，225 项无法仅凭元数据充分判断；环境、副本、外部工作区和远端历史不构成完整覆盖。因此也不能把 1–9 月自动认证为干净。

2026 年现有行情分区的快照身份及文件哈希已登记；文件当前截至 10 月 23 日。状态固定为 `QUARANTINED_NOT_CERTIFIED_CLEAN`，即使每日数据指针继续刷新，也不改变本次登记的文件身份。不将其用于开发、选择或此次评价。

## 3. 能否测出小改善

预先登记：日效用为 `mean(log1p(net_return)) - lambda * population_variance(net_return)`，主 lambda=5，敏感性 lambda=0/10；三年内分别做日期块重采样，4,000 次，主块长 20 日，敏感性 5/60 日；双侧 5%、80% 把握度。

2021/2022/2023 每年各 242 个收益日，共 726 日。没有把首次空仓初始状态当作一个收益区间，也没有把不同股票或种子当独立日期。

| 口径 | 每年效用百分点的近似 MDE |
| --- | ---: |
| 旧固定轮数与历史验证选轮数版本的实际配对差，主设置 | 13.50 |
| 主 lambda 下块长 5/60 日 | 15.76 / 12.35 |
| 主块长下 lambda=0/10 | 13.26 / 13.92 |
| 假设未来两路径等波动、相关度 0.95 | 10.36 |
| 同一假设下相关度 0.99 | 4.63 |

这些是年化效用单位，不是复利年收益。仅有 B0 不能识别未来 B3/B5 与它的协方差；旧版本配对只是设计参考，不是未来方法的实际 MDE。240 股开发基准已有数据/估值缺口，重采样还没有包含重训、搜索和完整方法族的不确定性。

结论：这段历史不足以可靠识别约 1–2 个百分点的小改善。保持净效用为经济主指标，阶段 A 用于机制诊断；成本下降只作辅助事实，不能看完结果后偷换主指标。阶段 B 前须重新登记实际比较路径的检验能力和最小有意义改善，不能承诺通过率。

## 4. 既有信号的多期限实测

这是现有五日模型的新诊断，**不是训练了 B1，也不是 B1 胜出**。共同覆盖为 706 个决策日，日内至少 20 个有效股票标签；95% 区间对每种覆盖下预设的八个区间作 Bonferroni 修正。

| 标签 | 共同样本平均 RankIC | 修正后 95% 区间 |
| --- | ---: | --- |
| 累计 1 日 | 0.0565 | [0.0426, 0.0704] |
| 累计 5 日 | 0.0838 | [0.0582, 0.1094] |
| 累计 10 日 | 0.0917 | [0.0583, 0.1252] |
| 累计 20 日 | 0.1070 | [0.0659, 0.1481] |
| 第 6–10 日增量 | 0.0638 | [0.0374, 0.0902] |
| 第 11–20 日增量 | 0.0644 | [0.0301, 0.0987] |

支持继续研究多期限信息：较远期区间也可见排序关联。不能推出较长持仓必然更赚钱、信息寿命为二十天，或这些关联独立于低波动/流动性暴露。累计不同期限的 IC 不可按数值高低直接选最优持有期。共同标签覆盖还条件于未来价格可观察性，逐期限可用覆盖也保留，不能只挑共同样本做部署承诺。

## 5. 梯度与代理诊断

使用历史 64/128 资产、3 日合成开发案例的固定 checkpoint，在当前代码下进行方向扰动和独立整手账户重放；没有新拟合模型，也没有用历史合成验收代替真实市场证据。

预设一个零均值、L2 归一化的方向，步长 `1e-5/1e-4/1e-3`，另做共同偏移 `+/-1e-3`；原求解 eps=`1e-9` 与局部诊断实例 eps=`1e-10` 对照。费用、仓位约束、持仓和原始源文件均未改变。

| 合成组 | 参数梯度 L2 | 首日下界活跃股票 | 首日预算使用 |
| --- | ---: | ---: | ---: |
| 64 股 | 2.30e-12 | 61/64 | 28.26% |
| 128 股 | 3.63e-12 | 125/128 | 28.27% |

原精度下很小的预测扰动会触发连续分数账户的微量交易，最低佣金使效用发生跳变，独立整手账户却可能完全不动。例如 64 股的方向 `+1e-5`，连续成本从约 52.08 元变为 137.08 元，精确账户成本仍约 23.73 元。

收紧求解精度使部分小步长的有限差分接近零，减少了这类数值费用变化；参数梯度仍未恢复。大步长下则存在活跃集变化，不能将中央有限差分当作同一光滑分支的真实导数，更不能据相对误差直接裁定所有自动求导都错。

判断：当前设置仍不适合直接投入 B3/B5 大规模经济比较。问题同时涉及活跃约束、数值尺度、非光滑最低费和分数/整手映射；没有证据归咎于某个唯一原因。原代理资格保持未通过，真实市场和 STRUCT 训练目标仍是开放门槛。

两个成功诊断子进程累计记录约 279.72 CPU 秒、323.09 秒案例墙钟时间；每个案例一个 CPU 线程，分别有 900 秒进程树超时上限。一次审计扫描和一次历史协议字段不兼容的失败均保留，没有记成成功。中断扫描未保留精确 CPU 计量，因此不伪称整个阶段有精确的 CPU 总数；没有启动 24 CPU 小时的阶段 B。

历史协议缺少后来新增的 `minimum_buy/minimum_sell` 字段。诊断使用单独派生协议，显式补当前中性默认，保留原 `buy_lot/sell_lot`；原协议、模型权重及数据哈希前后核对未变。新结果不能写回为历史核心的原始复现结果。

## 6. 检索结果与边界

开跑前 PubMed、CrossRef、arXiv 端点 3/3 可达，CrossRef MCP 实际检索也返回了可核验的 DeepTrader 等条目。后续 arXiv 查询及 OpenAlex 出现 HTTP 429，GitHub 树 API 返回限流，FinRL-Meta 官方 raw 文件可读。连通性检查不等于所有检索通道始终可用。

- [DeepTrader，AAAI 2021](https://doi.org/10.1609/aaai.v35i1.16144)：市场条件、股票关系、直接投资策略已有先例；摘要包含多空资金配置，不能当作本项目长仓约束的完整对照。
- [多期最小交易批次优化，Applied Soft Computing 2021](https://doi.org/10.1016/j.asoc.2021.107519)、[Finance Research Letters 2023](https://doi.org/10.1016/j.frl.2023.103964)：整手/批次、多期优化本身不是空白；本轮仅核实元数据，不把方法细节扩写为已经阅读全文复现。
- [FinRL-Meta A 股环境源码](https://github.com/AI4Finance-Foundation/FinRL-Meta/blob/master/meta/env_stock_trading/env_stocktrading_China_A_shares.py)：明确支持 100 股批次、买卖比例费用和费用后的奖励，证明这些工程要素已有重叠。所读文件不构成完整可卖批次、最低佣金、STRUCT 与独立账本一致性的验收。
- JKMP、AIPM、AlphaForge、E2EAI 的重叠见原研究设计；不重复声称端到端、动态因子组合或跨股票注意力是本项目原创。

尚未核实与本项目全部条件相同的工作，**不等于证明无人做过**。窄域现有技术审查仍是部分完成；创新主张与论文承诺保持开放。继续投入前应补齐相关全文和工程核对，不能把几项约束组合本身当作论文贡献。
