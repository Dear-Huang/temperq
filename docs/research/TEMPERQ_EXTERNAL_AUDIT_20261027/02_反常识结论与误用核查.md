# 反常识结论与常用方法的误用核查

“业内常用”不等于“业内普遍犯错”。本轮没有调查从业者采用率，因此下文区分条件性错误、实证反例、争议结论和本地已有成果。每条都说明应怎样证伪。R 编号对应 [DOI 表](05_文献DOI与来源.md)。

## 1. 限制自由度，可能反而降低样本外风险

**反常识点。** 在真实参数已知的最优化里，加约束通常不能改善原目标最优值；但用噪声协方差做投资时，no-short-sale 等约束可能减少估计误差造成的极端持仓，从而降低样本外风险。R03 的正式摘要直接支持这一点。R04 是 2019 年证明勘误，须与原文一起登记，不能只抄结论。

**不能推出。** 约束越紧越好、风险偏好无成本、任意单票上限均有效，或某个固定上限在 A 股仍最优。

**平台试验。** 固定预测与风险估计器，冻结上限候选；比较每条政策独立演进的净风险、成本、现金、暴露和约束绑定率。再固定约束比较不同协方差估计器，避免把正则化效果归给预测。用 R35 的协方差收缩作为对照方向，不能在同一测试段里继续挑收缩参数。

## 2. 相同的换手率，不等于相同的交易政策

R07 的工作论文全文直接讨论 buy/hold spread，R08 摘要比较 cheap-to-trade screening、低频再平衡和 banding。banding 可以在相近交易成本下保留更好的信号暴露。**门槛的形状和交易的时序，可能比总换手量更重要。**

这与你的 093453 和后续本地等换手/置换检验相邻，但不能把某篇论文中的支配关系外推给所有策略。本地后续封档也已指出，部分 L1 支配和部署主张不成立。

**证伪设计。** 保持信号、账户、成本和可交易性相同；做预算匹配的政策比较，分别控制平均仓位、现金和风险。强制退出与裁量交易分账；不可达的“精确等换手格”应保留为不可行，不事后删掉。

## 3. 剔除贵股票，并不必然比改变交易方式好

R08 摘要说明，仅交易便宜证券会损害策略的 gross exposure；减少不必要换手的方法在其样本中更有效。R32 基于机构实际交易数据指出，真实成本与早期估计可能差异很大，但其发达市场机构结果不能直接标定个人 A 股账户。

**证伪设计。** 比较“原股票池+banding”“剔除高成本证券”“原频率+部分调整”，列出成分替换、行业/规模暴露、gross、spread、impact、佣金和 net。不能假定减少成本的收益损失为零。

## 4. 成本排名相关性更高，尾部筛选却可能更差

这是你新增成本稿的已有结果，而非本轮外部新增发现。全体 rank correlation 是平均意义的排序目标；costliest-decile overlap 是尾部决策目标。两者没有必然同向关系。R33、R34 提供流动性测量背景，不能替代本地结果的独立复验。

**产品增量。** 把“全体相关—尾部重合—组合距离—执行成本—净后果”固化为一张通用卡。除了成本模型，也可审计风控模型：AUC 改善是否改善实际触发点的漏报/误报、干预成本和风险？后一推广是本报告的设计推论，尚无本轮市场实证。

## 5. 扣成本后，因子模型的排序会反转

R09 正式摘要直接指出，忽略交易成本偏向高成本因子模型；在其研究中，扣成本后的模型比较不同于 gross 比较。R10 进一步把风险与净成本后的有效前沿作为评价对象。

**不能推出。** 某个“赢家模型”在所有市场、容量和时期都赢。成本来源也可能是模型假设，不能当实测成交。

**平台输出。** 双列 gross/net 排序与逆序对，外加不同规模和成本参数的排序稳定性；不得只换最终一张净值图。

## 6. 1/N 可能难以击败，也可能在别的市场输得明显

R05 是估计误差下简单基线的重要文献，本轮只核正式题录及二级摘要佐证，未取得其正确全文，因此不引用具体胜率或参数结论。OpenAlex 还检索到 *Optimal and Naive Diversification in Currency Markets*（[DOI](https://doi.org/10.1287/mnsc.2016.2497)，摘要级线索），说明另一市场设定下可得到相反结果。它应作“不可普适化”的反例线索，后续使用前需核全文。

**产品含义。** 强制保留简单基线有价值；强制认定简单基线或复杂优化必然最好都不成立。

## 7. Sharpe 乘 √252，需要额外假设

R16 是正式理论来源；本轮已核题录，相关统计方法另以 DSR 全文、HAC 源码和方差恒等式交叉核对。对平稳、等间隔的算术超额收益，若日均为 μ、自协方差为 γₖ，则 q 日累计收益方差为：

```text
Var(sum(r[t+1:t+q])) = q*γ0 + 2*sum((q-k)*γk, k=1..q-1)
SR_q = q*μ / sqrt(q*γ0 + 2*sum((q-k)*γk))
```

只有相关项合计为零等条件下才回到 `sqrt(q)*SR_daily`。复利收益、缺失交易日和不规则时间间隔还需单独定义。此式不是对任何给定策略的数据结论。

**平台动作。** 提供频率、超额收益定义、有效日期、序列相关和 HAC/块区间；缺完整日历时不默认年化。当前导入审计已经避免在不完整导出上年化，应保留这个边界。

## 8. t>2 或 t>3 都不是万能门槛

R23 的研究指出大量因子搜索下通常的 t>2 不够；它不意味着任意策略都可一律用 t>3 认证。R20/R21 的候选族检验、R17/R18 的搜索调整，以及真正冻结的外层样本分别解决不同问题。

**常见错误。** 只对最终赢家做普通 t 检验；把探索期改名为独立测试；平台内记录 5 次尝试就忽略用户在别处试过的 500 次。

**平台动作。** 搜索来源分成“本平台观察到”“用户声明外部搜索”“未知”；本地哈希只能关联材料，不能证明未删记录或不存在平台外尝试。

## 9. 没有显著 alpha，不等于 alpha 为零

R24 的基金 FDR 方法、R25 的功效批评、R26 的作者回复应成组阅读。短样本、低信噪比下，零 alpha 与“无法分辨”可能混淆。回复指出误分类程度也取决于样本和参数，不能仅引用争论的一侧。

**平台动作。** 结论至少分“支持正向效果 / 支持未达经济门槛 / 证据不足”，同时给经济阈值、区间和可检测差异。不得把不显著样本外收益写成“策略无效”。现有 `conclusion()` 的 INCONCLUSIVE 状态可直接复用。

## 10. 很多异常不可复现，与很多因子可复现，可以同时有依据

R27、R28、R29 的样本、原文复刻程度、断点、微盘股、权重、多重检验、因子聚类和国际样本不同。比较“复制原论文的统计结果”和“形成可投资的净成本策略”也不是同一个任务。不能用其中一句结论宣布整个行业造假或整个因子库都可靠。

**平台动作。** 将 `replication_target` 写成“原文同口径 / 外部数据迁移 / 成本后可投资性 / 账户实际执行”，每类独立报告。

## 11. 持有期，不等于信号年龄

FIFO 从实际成交中恢复批次年龄，信号年龄则需要冻结的信号版本和可用时间。卖出后的持有期分组含事后选择；未卖出批次还右删失。你现有 `audit_research.py` 和策略审计文档已经对此正确划界。

**新增量。** 连接 093459 的 signal vintage 数据契约，而不是把 FIFO 图改名“最佳持有期”。Alphalens 的多期限 forward IC 也不能直接替代固定 vintage 的年龄曲线。

## 12. 删除某只股票的贡献，不等于不买这只股票的策略收益

现有报告将去除贡献明确标成会计敏感性，这是正确边界。真正排除证券会改变再分配、现金、后续整手、费用和交易约束。

**验证。** 若无法取得完整候选池及历史行情，只能显示固定成交的会计敏感性。不得称它为“排除后回测”。理论基础是自融资账户恒等式与 R01 的持仓状态演进，不需要制造因果结论。

## 13. 低回撤可能只是多拿现金

检查平均仓位、beta、波动、行业、规模和现金收益；不同匹配方案回答不同问题，不能通过只选择有利的匹配基准来证明治理有效。现有 README 已有平均实际仓位匹配对照，新增量是把匹配协议和局限贯通到导入审计及政策族。

## 14. 有效持仓数，不等于独立风险来源数

`1 / sum(w_i^2)` 衡量持仓集中度，无法反映股票间相关性。一百只高度相关的股票可以具有很高的持仓有效数而只有一个主要风险方向。此为定义与组合方差的数学区别，不是本轮某篇论文的实证发现。R35 提供估计协方差的理论工具。

**输出。** 将“持仓有效数”与“风险分散”分开；后者需风险模型并说明估计误差。不能用更多股票自动给更高审计分。

## 15. SHAP 可加，不代表经济贡献可因果相加

R31 支持相关特征下的解释问题。把治理参数逐个切换的增量相加，也会因交互项不同而依赖切换顺序。

```text
interaction = Y(A=1,B=1) - Y(A=1,B=0)
            - Y(A=0,B=1) + Y(A=0,B=0)
```

四格都需同口径且可实现。上式是有限差分定义，不证明市场因果性。若用 Shapley 汇总，需要事先定义价值函数、基准及可行联盟；含不可行政策组合时不能自动补值。先报告单轴效应和交互，比强行输出总贡献百分比可靠。

## 16. 哈希、按时留痕与数据真实性是三种证据

本地哈希能验证保存后材料是否变化，不能单独证明当时已存在、未删试验或数据真实。公开项目的已知前视 bug 修复也表明“开源”不等于“无前视”。Open Source Asset Pricing 官网记录 2024-10-14 修复 `AnnouncementReturn` lookahead bug；这是一条具体版本事实，不能扩大为整套数据不可用。

**平台动作。** 版本、采集时点、首次可用时点和外部可验证时间戳分开；遇到供应商修正要标记哪些旧报告受影响。

## 17. 持续看报表，会改变推断条件

R30 的 confidence sequence 研究支持任意停止时点的时间一致推断，但需满足对应随机过程和尾部条件。不能直接把股票日收益当独立、有界样本套公式。

**首版选择。** 固定复核周期、登记查看与策略调整次数、冻结触发门槛；先建立监测协议。高级时间一致推断留到有完整前向数据后。

## 18. 监管文件也有版本生命周期

Federal Reserve 官方 [SR 26-2](https://www.federalreserve.gov/supervisionreg/srletters/sr2602.htm) 明确替代 SR 11-7 和 SR 21-8。不能把旧文件称“现行最新”。它本身适用于银行组织，不能据此称 TemperQ 通过监管认证。

可借鉴的是真实业务目标、有效挑战、模型清单、结果分析、持续监测和例外处置。它尤其支持一个产品原则：验证要与用途和重要性匹配，不能让所有用户填同一套无关表格。
