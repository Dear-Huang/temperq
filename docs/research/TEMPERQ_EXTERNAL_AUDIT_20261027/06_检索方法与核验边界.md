## 检索方式与范围

1. 先读本地治理总纲、后续撤销/封档记录、投稿状态总表、已录用稿摘要、成本稿正文相关段落、当前产品边界及关键源码。
2. 使用 Crossref 发现和核验基础文献；对近期方向检索 arXiv；对于题名、摘要与对照观点，补 OpenAlex / Semantic Scholar；再到作者官网、GitHub 和监管官网查全文或工程状态。
3. 概念组包括：backtest overfitting、deflated Sharpe、multiple testing、reality check、superior predictive ability、model confidence set；portfolio construction/non-standard errors、wrong constraints、naive diversification；cost mitigation、dynamic trading、implementable frontier、implementation shortfall；attribution、dependent features、confidence sequences、model risk management。
4. 结构化留存 36 次 Crossref 发现检索、2 次 arXiv 检索和 8 次 OpenAlex 跟进；另有 DOI 精确查找、作者页和代码定位。初步探索性查询并非全部包含于这个计数。
5. 先按 DOI 小写去重；期刊正式稿与 SSRN/NBER 版本合并为同一研究线，优先记录正式 DOI，保留工作论文作为阅读全文或摘要的入口。

本轮主要覆盖英语金融、资产定价、组合优化、统计推断及监管资料；没有覆盖付费终端、全部券商内部资料或中文数据库。因此不能声称穷尽互联网或确认某个构想“业内无人做过”。

## 来源失败、修正与降级

- Semantic Scholar 初次主题检索和两次 arXiv 检索无结果；零命中不能证明没有研究。旧 coverage 提到的 `2603.20319` 本轮未取得足够独立证据，未作为新增结论的承重来源。
- Google 搜索请求连接重置/超时；未据此推断搜索结果。主要检索改由可用的学术 API 和官方页面完成。
- DOI 精确批量查找中三条遇到 HTTP 429，随后逐条重试成功；最终选定 41 条均有 Crossref 正式响应。元数据匹配不等于全文核验。
- 初始检索曾返回 Practical Applications 的 DSR 解读；最终选用原始 JPM 2014 论文和 2026 正式论文，避免错把解读当原始来源。
- `10.1111/jofi.12585` 查到的是政府信贷论文，属于错配候选，已排除；没有靠“DOI 可以打开”认定引用正确。
- SR 11-7 原链接与附件返回 404，后续官网 SR 26-2 明确说明其替代关系；依据官方新文件，不由 404 推断废止。
- 某些作者 PDF 链接 404，或 200 后重定向到学校师资主页；均未当成功取到全文。例如 1/N 的旧 LBS 链接只返回 faculty profiles。
- 原始 OpenSourceAP 猜测地址返回 404，已从作者官网找到正确仓库；JKP 旧仓库 README 指向新仓库，已核验迁移。
- GitHub contents API 的 `sha` 是 blob SHA，文件最近修改的 commit 已另行查询。`04_开源代码与接入选择.md` 将两者分开，并给出提交固定的源码链接。
