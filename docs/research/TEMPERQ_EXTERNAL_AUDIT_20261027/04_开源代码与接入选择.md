## 版本与项目状态的具体发现

1. `AndrewYChen/OpenSourceAP` 本轮 API 返回 404。作者官网实际链接为 `OpenSourceAP/CrossSection`，已纠正，不把失效地址作为最终代码来源。
2. `bkelly-lab/ReplicationCrisis` 的 README 明确写着不再维护，并指向 `bkelly-lab/jkp-data`。GitHub 的 archived=false 不足以判断维护状态。
3. Open Source Asset Pricing 官网记录 2024-10-14 修复 AnnouncementReturn 的 lookahead bug。基准数据必须记录 release/版本，不能以项目名称替代数据身份。
4. AssayingAnomalies 的 README 说明 MATLAB、WRDS、CRSP/Compustat 以及较高内存需求。可借鉴检验协议，不能承诺下载代码即可在个人免费数据上完整复现。
5. cvxportfolio 当前 GPL-3.0；TemperQ 当前 AGPL-3.0-or-later。未作法律兼容性结论，不能沿用旧 MIT 主仓库时代的判断。工程上先作为可选连续对照，避免重写 A 股成交逻辑。

## 优先适配次序

`arch` 统计比较适配 → 现有账本/政策族接口 → statsmodels 统计对照 → Alphalens/Pyfolio 指标交叉核对 → cvxportfolio 连续问题基准。Qlib/Lean 用于有明确差异的成交规则验证，避免扩建第二套账户引擎。skfolio/Riskfolio/QuantStats 保留参考，不因库功能多而成为新增依赖。
