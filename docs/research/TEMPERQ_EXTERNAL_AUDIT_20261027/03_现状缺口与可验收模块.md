# TemperQ 当前缺口与可验收模块

本轮为只读代码/文档审查和外部研究，没有运行用户策略、重算论文结果或修改平台功能。下列“已确认缺口”指报告入口或数据契约的缺口，不代表发现了账户算错或收益错误。源码以本地工作树 2026-10-27 快照为准，既有未提交改动均保留。

**同日深化：** 本文 M01–M08 是模块编号，不是开发顺序。根据用户对“只批评、不给改法与经济效益”的担忧，优先级已在第三节改成动作估值与政策净差优先。论据见 [07](07_从诊断到改法与经济代价.md)，建议字段与验收见 [08](08_实务证据与动作定价契约.md)。

## 二、最小可交付的八个模块

### M01 试验族视图与选择风险

**收益给用户：** 看到“这个策略用了多少次可观察到的尝试、它是否只是最好的那一格”。

**复用：** `ledger.py`、训练历史和验证候选审查；`strategy_audit_store.py` 的追加报告。不要新增第二套可覆盖旧记录的数据库。

**新增契约：** `family_id`、共同数据/信号/成本/账户身份、探索/验证/外测阶段、预声明候选清单、失败和未运行状态、候选选择规则、外部尝试声明。原始导入策略只有一条曲线时，搜索诊断应为 `unknown_external_search`。

**验收：** 改配置/重复计算/失败/取消均保留身份；追加候选改变族范围时生成新评价，不给旧报告补造当时未知的候选；用户删除历史无法被哈希自动排除，报告应诚实标明本地范围。

**统计：** 首批接 SPA 与 MCS。把逐日损失约定写清，例如 `loss=-net_return`；风险偏好若进入效用，则记录参数和单位。共享日期抽样以保留候选相关性，不能分别重抽样后比较两组无配对均值。block length 做预声明敏感性；随机种子固定只为复算，不代表统计稳健。

### M02 构建政策审计与交互

**收益给用户：** 分清预测、组合映射和交易节奏分别改变了什么。

**输入：** 冻结信号、点时全候选池与行情、构建公式、初始账户、费用和交易规则；只有实际持仓不能恢复所有可选股票。

**候选：** 原政策、不动、单轴池宽/权重/带宽/速度候选。每条长期政策从共同的初始账户独立演进，不能每天重置到原策略的实际持仓；单步决策复演则可共享当日初始状态，但必须标为另一估计对象。

**输出：** gross、commission、tax、spread、impact、net、风险、现金、暴露、未完成目标、违约与不可行格；差异和交互都用明确单位。先做两轴四格，确认归因顺序不被隐藏，再讨论 Shapley。

**验收：** 同一政策经新接口回放能重建原有账本；更改候选顺序不会改变结果；无信号、停牌、涨跌停、锁仓和公司行动缺口留痕。反事实是声明执行模型内的结果，不是实际市场因果收益。

### M03 约束与偏好的边际代价

**收益给用户：** 看到“为何不能实现目标、哪一条限制最有影响、接受多少偏离能省多少钱”。

**输入：** 现有 `ReviewInput` 和规则，不需要训练新模型。优先于数据昂贵的因子归因。

**输出：** 保持持仓、贴近目标、容忍偏离省费三个已有候选，增加小规模容忍带扫描和可行性状态；每条约束列 slack、是否绑定、绑定区间、必要卖出下界和证据。用户未授权的硬约束不能自动放宽。

**关键数学边界：** R37 的连续凸规划对偶变量，在适当可微与正则条件下可解释为目标对约束的局部敏感性。TemperQ 含整数股数、固定最低佣金和基数约束，不能把 HiGHS MILP 的某个对偶数直接称“每放宽 1% 可赚多少”。应另算离散情景：

```text
relaxation_effect(delta) = objective_at_changed_bound - baseline_objective
```

同时报告该 objective 是元、权重偏离还是模型效用，以及是否证明最优、求解 gap、限时和不可行/未知状态。当前目标是费用与跟踪偏离时，这个差不是收益 alpha。

**验收：** 小账户可穷举时对照；复算费用、锁仓与整手；容忍带扩张只给可行集/已证明最优值的数学关系，不强迫所有启发式候选单调；超时无解不等同于已证明不可行。

### M04 成本模型的决策验证

**收益给用户：** 看到“一个更复杂的成本模型是否值得采用”。

**复用：** 新增成本论文的两部分模型与验证逻辑；`audit_research.py` 的 tick/quote 匹配；费用复算继续使用冻结日期规则。

**输出四层：** 观测费用；同一成交的模型成本/压力；改变决策后的独立政策回放；后续真实/按时纸面记录。层间不互相冒充。

**最小实验：** inverse price、现有两部分模型、明确的替代 proxy；按事先冻结的最贵尾部和完整排序分别评估；计算替换清单、换手、仓位和成本差。原型若只有已成交股票，必须标 `selected_trade_sample`，不能外推全候选池 tail recall。

**验收：** 未计 spread 才能额外施加 spread 场景，避免重复扣费；佣金/税/价差/冲击分别对账；开盘竞价、被动挂单和日均报价不自动视作同一实测成本。每边 bp、双边换手及人民币/千元/手的单位写入 schema。

### M05 目标—成交偏离与实现短缺

**收益给用户：** 分清“选错股票”和“没买到、买晚了、付得贵”。

**新增最小表：** `decision_id/order_id/parent_id`、批准目标量、decision time/price、release/arrival time/price、订单与撤单事件、逐笔成交价量、显式费用、终止/估值时间及价格、受阻原因。无完整订单时不从错误日志推断失败率。

**一种可复算定义：** 对买入 Q 股、决策价格 P0、已成交 qj/Pj、终点未完成股数 U，在统一终点 PT 下，价格口径的实现短缺为：

```text
IS_currency = sum(qj*(Pj-P0)) + U*(PT-P0) + explicit_fees
Q = sum(qj) + U
```

卖出按相反价格方向定义，成本为正的符号约定必须一致。若目标撤回，要说明 U 是初始批准目标、最终有效目标还是区间政策的剩余量；不能事后选择对策略有利的口径。延迟和成交部分再按 arrival price 划分，但终点价格变化可能含市场漂移，不等于全部由市场冲击造成。

**来源：** R11 实现短缺与 R12 执行风险—成本权衡。上式为明确口径的会计构造，未在本轮真实订单上验证。

### M06 暴露与基准归因

**收益给用户：** 识别超额表现来自市场、行业、规模、流动性还是策略选择。

**输入：** 同频率总回报、现金收益、基准、点时行业/风格暴露和候选因子收益；明确是否可投资、gross/net 及本土市场口径。不能直接把美国因子当 A 股基准。

**输出：** 先展示暴露覆盖、现金和行业，再做基准相对归因；多期收益要记录链接方法，不能把货币贡献直接拼成复合收益。时序回归至少带 HAC/日期依赖说明，候选因子过多时仍需搜索控制。

**验收：** 归因合计闭合、无暴露时不填零、变更基准生成新版本。时间序列 regression alpha 依赖所选模型，不称为无条件真实 alpha。

### M07 预期偏离与持续监测

**收益给用户：** 看见偏离发生在哪层，并有可执行复核动作。

把预期写成结构化 `expectation_card`：适用股票池、账户规模、信号刷新/年龄、交易预算、成本范围、目标完成期限、评价窗口、阈值依据、复核频率、责任与回退方案。预期区间若仅来自训练期，应标样本内。

偏离分类：输入缺失/PIT 违规；风险/现金/规则偏离；成本模型偏差；未完成目标；gross 信号衰减；净结果不足。输入损坏优先修数据，不能自动宣布信号失效；有异常也不自动改目标。

**来源：** SR 26-2 的 outcomes analysis / ongoing monitoring / effective challenge；R30 仅作为后续连续监测推断方向。先用冻结复核频率与累积查看次数，避免上线未经条件校验的 confidence sequence。

### M08 可携带证据与供应商版本影响

**收益给用户：** 能复核“用了哪版数据、规则、模型、方法、参数，结论在哪个范围成立”。

扩展现有 evidence JSON：数据来源/版本/时点字段，算法版本、规则生效日期、输入行、会计闭合、模型成本假设、候选族、选择与外层检验状态、风险因子版本、实际执行证据、复核与例外。

数据供应商更正后，列出受影响报告，追加一次按新数据重算；旧结果保留原口径。OpenSourceAP 的已知 lookahead 修复可作为版本影响的设计案例，不是自动否定该项目。

## 三、实施顺序与停止条件

| 优先级 | 先做 | 通过条件 | 停止/降级条件 |
|---|---|---|---|
| P0 | M03 可估值动作、M08 证据字段；复用试验账本；M04 先核单位与费用 | 具体交易/不动候选；费用—偏离差与盈亏平衡；最终硬约束通过；版本留档 | 无收益预测不报净收益最优；缺报价只做明确场景；未知不填零 |
| P1 | M02 政策回放、M04 决策验证、M07 前瞻记录；M01 贯通，先复用已有成对统计 | 原政策可重建旧账本；候选独立演进；毛/成本/净差闭合；区间与失败保留 | 改善后仍不经济可否决；差异不足可维持原政策；不为复杂模型牺牲可验证性 |
| P2 | M05、M06、真实信号年龄/容量 | 用户确有完整目标、订单或因子数据，存在可核算决策后果 | 只有成交表不伪造未成交；只有已买股票不评全股票池 |
| 后续 / 研究 | SPA/MCS 的完整接入、MPC、economic feature importance、连续监测推断 | 简单基线未解决；试验范围、目标与数据条件明确；外层样本冻结 | 只提升代理指标、没有组合/执行后果，或收益差低于可检测门槛 |

这里的优先级是依赖关系和产品判断，没有把迭代数当成已估算的工期。本轮没有证明这些模块会提高任何用户的净收益；可保证先让问题和证据更可见，效果仍要经过冻结后的复验。
