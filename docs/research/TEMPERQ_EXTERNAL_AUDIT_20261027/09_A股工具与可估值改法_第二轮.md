# A 股第二轮：工具、具体改法与经济验证

日期：2026-10-27。承接 [07](07_从诊断到改法与经济代价.md) 的任务：除了指出问题，还要找到可以执行的修正，并区分已知费用、历史净差和未来不确定价值。本轮重点从通用组合方法转向中国股票的交易约束、组合落地和执行。

核对了5个代码仓库的元数据，取得并按 Git blob 校验30份固定提交文件；补读官方API、论文全文和公开讨论。没有安装这些项目、运行其策略、连接券商或修改 TemperQ 功能。证据定位、DOI、许可和未解决问题见 [10_A股来源与实现核查.md](10_A股来源与实现核查.md)。

## 1. 最值得吸收的能力

**找到了，而且 A 股的实用增量主要在“目标怎样变成可成交的组合”与“执行到底少付多少钱”。** 当前证据支持下列选择，不支持宣称某个库已证明能让 TemperQ 用户持续增收。

| 工具 / 子模块 | 有哪些具体动作 | 能估计什么经济后果 | 对 TemperQ 的位置 |
|---|---|---|---|
| RQAlpha 智能目标组合下单 | 将停牌、涨跌停、可卖数量转换为权重界限；可调资产间缩放；处理整手、费用、现金；先卖后买并返回原因 | 给定价格下完成目标、剩余现金、费用与偏离；长期收益仍需回放 | 完整目标落地的对照；商业许可有额外限制，不能直接作为免费依赖 |
| Qlib TopkDropout | 控制替换数、最低持有期、可交易集合与涨跌停买卖方向 | 调仓强度带来的毛结果、成本、现金及净差 | 候选动作生成与对照，不只是再算IC |
| Qlib 指数增强优化器 | 限制换手、个股相对基准偏离与因子偏离，求权重 | 指定模型的风险—预测收益权衡 | 可选连续基准，不能替代A股整数账户规则 |
| WonderTrader 股票执行器 | 按目标/可用仓位和盘口分单；报价偏移、间隔、超时撤单、VWAP调度 | 完成率、执行短缺、撤单与费用比较 | 执行动作与事件结构；MinImpact名称不代表已证明最低冲击 |
| Qlib RL执行 + OPD论文 | 针对既定母单调整各时段交易量，与TWAP等比较 | 论文的A股历史价格优势，不是用户净收益 | 后续研究基准，先有母单、行情和可成交验证 |
| VeighNa 的 vnpy.alpha | 因子—模型—股票示例—回测一体化；替换数、持有期和资金利用率 | 可建立简单构建基线 | 所读Alpha日线撮合有明确简化，适合作限定范围的模板 |
| 迅投 XtQuant 文档 | 委托、成交、可用持仓查询和回报；订单与策略标识 | 用真实记录核对计划落实，继而验证效果 | 只读导入契约参考，本轮未连接实盘 |

将 Qlib 的不同模块分开，是因为选股调仓、连续权重优化和母单执行解决三个不同问题。将它们叫成一个自动优化器，会混淆收益来源。

## 2. 一个有 A 股经济结果的研究：OPD执行优化

Fang等的 Universal Trading for Order Execution with Oracle Policy Distillation，AAAI 2021，DOI：[10.1609/aaai.v35i1.16083](https://doi.org/10.1609/aaai.v35i1.16083)。已读全文，Table 2已渲染核对，见 [原表截图](evidence/ashare_round/opd_page_7.png)。

它处理“某股票今天要卖/买既定数量，如何分配到日内各时段”，不是预测该买哪只股票。方法以未来信息训练教师，再将行为蒸馏给仅使用当时信息的学生；教师在测试与实际使用时移除。**训练教师看到未来，不等于部署学生必须看到未来；但测试数据边界必须核查。**

论文使用2017年至2019年上半年的A股分钟数据，测试期为2019年5—6月，测试表列33,176个订单、855个证券标识，作者称验证/测试保留中证800相关股票。报告平均六个不同随机种子的模型结果。

| 论文Table 2方法 | 测试集平均价格优势PA，bp |
|---|---:|
| TWAP | 0 |
| AC | 2.33 |
| VWAP | 0.32 |
| PPO | 2.52 |
| 无教师的学生OPDˢ | 5.19 |
| OPD | 6.17 |

按原表舍入数，OPD相对TWAP为 **6.17 bp**，相对VWAP为 **5.85 bp**，相对无教师学生为 **0.98 bp**。这是按订单平均的价格优势；论文公式以卖出收入为讲解口径，买入方向相反。不是名义金额加权的真实现金节省，更不是日收益、年化alpha或账户每年多赚6.17 bp。

TWAP的PA为零来自该模拟的时段与平均价格基准定义，不代表真实TWAP执行没有手续费、冲击或未成交成本。

决定能否迁移的边界：

1. 作者忽略佣金和交易所费用，定位于机构执行。小账户最低佣金可能改变优劣。
2. 冲击以奖励中的二次惩罚表达，并假设市场下一步恢复；不是实际永久冲击、盘口排队和本策略反作用的完整仿真。奖励改善不等于现金节省。
3. 测试仅两个月，不能证明跨制度、规模和市场状态长期稳定。本轮未重跑原数据。
4. 当前Qlib示例不是原论文结果的已确认等价复现。README明说训练模拟器不限制交易量，而回测器另有约束；教程的checkpoint平均也不能当成多次独立训练。
5. T+1股票上的卖出母单先要有可卖库存。执行算法不能把今日新买股份变成可卖股份，不是解锁T+1的办法。

产品启示：**可以给分单节奏处方，但要先固定母单、期限、初始可用库存和终点未成交处理，再比较完整费用与完成率。** 先接TWAP、预声明成交量曲线、简单参与率基线，条件具备再比较RL。

## 3. 最值得先做的具体动作

### A. 股票卖不掉时，重算可调整组合

RQAlpha智能目标组合接口把受限持仓变成权重上下界，在剩余可调资产上尽量保持目标比例，再处理数量和现金，返回每个资产的拒绝原因。估值价格与挂单/撮合价格分开，是值得注意的信息时点设计。

TemperQ可围绕已有规划比较保持现状、仅完成可实施部分、在允许的可调股票中重新分配三种动作。报告受阻原因、目标完成额、锁定敞口、预计费用与现金。不得自动改变用户股票池、风险偏好或硬限制。

**不改代价：** 当日价格假设下能算多持多少现金、少实现多少目标和费用差；未来少赚多少依赖未实现敞口的后续路径。拒单减少不能单独当收益改善。

源码：[智能调仓固定提交](https://github.com/ricequant/rqalpha/blob/6a996af2876013615ceea141a97bad94ac4ab7f3/rqalpha/mod/rqalpha_mod_sys_accounts/api/order_target_portfolio.py)。该仓库有额外商业限制，本轮仅审阅，不提出复制接入。

### B. 整手、最低佣金与持仓替换强度一起调

Qlib和VeighNa示例提供topk、n_drop、最低持有期等旋钮。可以从每次替换哪些股票、最多替换多少开始，与上一轮双门槛和仓位带比较。最低持有期是政策约束，不等于测得的最优信号寿命。

先弄清收费对象。RQAlpha按order_id跟踪最低佣金：**同一委托多次部分成交，与多个独立子委托，不是相同最低收费对象。** 用户合同可能不同，要用合同和交割单确认，不能假定每条成交记录各收一次最低佣金。

**改法：** 对真正独立、允许合并的同方向小委托生成合并/缓冲候选，保留必需风险退出。比较费用、延迟风险、整手偏离与暴露；不能任意净额化跨时段、相反方向或不同授权的交易。

**不改代价：** 已发生收费差可复算；未来先给合同条件下费用差与盈亏平衡价格变动。毛收益机会成本未知时不能填零。

### C. 执行优化要做母单实验，不能只换成交价字段

WonderTrader的股票MinImpact单元有盘口比例、报价偏移、间隔、超时撤单和实际/可用仓位处理；VWAP单元读取外部成交曲线后调度。它能指导改哪些参数、记录哪些事件，没有自动给出最优参数或节省额。曲线必须事前可得，不能用当日完整未来成交量生成计划。

实务证据：[RQAlpha #833贡献者回复](https://github.com/ricequant/rqalpha/issues/833#issuecomment-2041818453) 说明算法单接口“并不是在回测中真实地执行一个算法单，只是让订单以理想状态下算法单的价格成交”，目的是中低频研究剥离执行影响。这有研究用途，但不能证明TWAP/VWAP子单的成交率、滑点或冲击优势。

**改法：** 同一批准母单比较实际执行、TWAP、事前曲线与简单参与率，再加报价/撤单候选。统一截止时间与未成交估值。

**不改代价：** 可比完成量下，卖出比较多收到的货币、买入比较少支付的货币，再扣费用差；未完成量纳入统一终点短缺。VWAP差额不能全叫可避免损失。

### D. 指数增强先明确授权，再优化

Qlib的EnhancedIndexingOptimizer给出预测、跟踪风险、换手与风格偏离的组合问题，但有三点不能直接拿来给收益标价：

- 默认把收益按横截面标准差与风险尺度重缩放，目标值不是人民币预期收益。
- 首次失败后尝试移除换手约束；源码会记日志，但只看最终权重的报告仍可能漏掉放宽。
- 成功后删除小权重并归一化，最终组合需重验个股/因子界限、现金和整数股数。

**改法：** 保留原约束的不可行/未知状态；硬换手预算不可删除；允许软化时另存有明确差异的候选。连续解仍经既有A股账户规划，最终重验。

**经济价值：** 多花的费用、额外换手与风险偏离换来什么模型目标或历史净差；求解成功不能等同回报提高。

## 4. 反直觉或容易长期沿用的误设

| 常见假设 | 核对事实 | 修正方向 |
|---|---|---|
| 达到涨跌停就双向不准交易 | Qlib默认forbid_all_trade_at_limit=True，连涨停卖、跌停买也屏蔽；注释承认比现实更严 | 按方向、真实限价和流动性区分；允许申报仍不保证成交 |
| 统一9.5%或10%阈值即可 | Qlib历史示例0.095；VeighNa所读Alpha撮合用昨收×1.1/0.9 | 证券—板块—日期—状态规则及实际限价；不把换阈值当调优获利 |
| 默认成本按历史变化 | RQAlpha采集版本pit_tax=False，未开时税率初始化0.0005；开启才在2023-08-28节点前后切换 | 记录费率版本/生效日；单节点不等于全部历史税制 |
| 涨跌幅字段名称对了就行 | Qlib #1404用户发现自有change应除100，否则大量订单误判不可交易 | 导入小数/百分数单位契约，核对逐单原因；别盲改策略 |
| 填平缺失价格只影响净值 | VeighNa所读Alpha路径为缺bar建旧收盘价占位，再参与订单交叉；交叉函数未查成交量 | 估值填充与成交资格分离；对缺失/停牌已有挂单专项复验 |
| 指数超额都是预测贡献 | Topk新买入近似等额分配、存量随价格漂移，不是市值加权 | 保留指定指数，再加同池构建基线，分清权重/规模/现金 |
| 执行训练好，真实成交也一样 | Qlib说明训练简化器可全成交，正式回测另有约束 | 冻结政策后用更严格回放与母单记录复核 |

这些是特定版本、设置和数据契约的风险，不能宣称整个项目或A股量化行业都算错。源码风险是静态发现，本轮未运行复现，没有编造影响金额。

一个不需编账户就能说明的量级：RQAlpha开关涉及的0.001和0.0005税率差为 **卖出金额的5 bp**。在代码支持且费率适用的历史窗口，固定原成交的差额为“适用卖出金额之和×0.0005”，不是本金的5 bp，也不是优化创造的收益。真实费率须按日期和标的核验；未代入用户成交。

## 5. A股归因应有本土构建基准

Liu、Stambaugh、Yuan的Size and value in China，JFE 2019，DOI：[10.1016/j.jfineco.2019.03.008](https://doi.org/10.1016/j.jfineco.2019.03.008)。已读NBER工作论文，DOI：[10.3386/w24458](https://doi.org/10.3386/w24458)。

该研究构建中国因子时排除最小30%公司以减少当时壳价值影响，价值因子用盈利价格比，而非直接照搬账面市值比。说明收益来源与制度、样本和构建有关。

具体动作是增加本土、点时、可投资范围明确的基准，比较规模、价值、权重和现金暴露。风格约束方案可成对回放，但**不能把剔除最小30%当今天所有策略的处方**，也不能把回归alpha减少当亏损。历史制度与今天不同，需复验。

公开 [Qlib #2315](https://github.com/microsoft/qlib/issues/2315) 讨论类似基准问题。已核对默认基准和买入分配，没有复算该用户报告的收益数值，故不用来定价。市值指数仍可作为有效投资基准，关键是不把超额全归预测。

## 6. 推荐落地顺序

| 顺序 | 用户得到什么 | 输入与验收 |
|---|---|---|
| 1. 可执行计划比较 | 哪些目标受阻、如何分配可调资金、费用与偏离多少 | 复用现有治理；实际可卖/冻结、现金、点时规则和计费对象；数量后重验 |
| 2. 调仓政策净价值 | 少换股票、延长持有或回带边界，历史省费是否超过机会损失 | 全候选信号、共同初始账户、独立演进；毛/成本/净差与配对区间 |
| 3. 母单执行比较 | 什么任务下改参与率、时段、报价更合适，不成交风险是什么 | 母子单与时点报价；统一截止/未成交估值；先简单基线 |
| 4. 实际反馈闭环 | 推荐是否完成，随后经济结果是否支持 | 借鉴XtQuant标识与事件做只读导入；费用另接交割单；前瞻留档 |
| 后续 | 指数增强/RL独立研究比较 | 预测/风险单位可解释、数据足够；代理奖励与现金分开 |

这轮最强增量是将 **受阻后的组合修复、按委托归属的成本、真实母单执行结果** 连到已有平台。工具能提供具体动作结构；可核实的公开经济结果主要仍是历史模拟，没有找到能直接迁移为用户长期实盘增益承诺的独立证据。
