- `F`：已获得论文全文或官方原文并读到与结论直接相关的段落。
- `A`：已从 Crossref / OpenAlex / arXiv 等获得摘要或正式元数据；结论限于摘要可支持的范围。
- `M`：只作方向线索，需后续取得全文或在用户数据上复验。
