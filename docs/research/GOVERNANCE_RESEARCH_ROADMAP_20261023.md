# 治理研究转化：从可用产品到可检验的技术增量

日期：2026-10-23。工程规划与研究假设，不是效果认证。与 [治理 SPEC](../specs/GOVERNANCE_SPEC.md)、[已核验的文献与工程](GOVERNANCE_ML_EVIDENCE_20261023.md) 配合使用。

## 目标与分层

1.0 让普通用户把纪律变成可运行、可解释、可版本化的账户政策。后续研究允许改进风险、交易成本或净效用；“算法不可能超越”没有证据，但“已经超越其他平台”同样没有证据。竞品已有优化、风险与执行能力，是否独特须比较具体功能、输入和验证口径。

用成熟方法搭基线，研究集中在日频 A 股小账户的约束和成本。统一顺序是：信号 → 风险/机会估计 → 约束决策 → 原有成交账本。ML 可以参与估计或学习少量政策参数；不让估计器绕过授权、整手、T+1 和现金会计。

## 首个增量课题：成本感知的调整速度

先实现固定部分调整作为可解释基线，再决定是否训练 ML。形式为 `w_intent = (1-a) * w_drift + a * w_target`。`a` 表示本期向目标靠近多少，取值在 [0,1]；真实目标还须通过授权与可交易性处理。退出股票池、现金不足和硬限制的处理先固定并记录，不能靠平滑延缓必需的风险处理；受阻时记录目标与实际偏离。无可行解应停止或采用事先定义的安全方案，不能偷偷归一化突破上限。

候选学习输入只用决策当时已知的信号变化/年龄、当前持仓与风险、账户资金与订单规模、成本估计。不把截面排名分数当成可与 bp 直接相减的预期收益。若学习交易净收益，先在训练期滚动样本外分数上建立数值校准，固定期限与决策时点；不能用本轮测试区间决定信号方向、阈值或系数。

优先考虑固定小网格、低维政策或正则监督模型。其目标可以是风险/换手约束下的成本或净效用，不能只最小化成本从而学会一直不交易。保留立即调整、固定速度、排名保留带、成本禁区作为同信号基线；学习速度必须先胜过这些低成本候选，才有加入默认产品的理由。

STRUCT 可以提供与价格最小变动单位有关的价差估计，连接成本与账户规模。现有包输出的是完整报价价差 bp；小订单单边近似约为半价差，不能当成已经实现的有效价差或大订单冲击。使用原始价格和当时已知的月度输入；接入时需明确时间滞后、历史制度费率、滑点叠加与避免重复计费。账本尚未接入，不能宣传“全成本”。

## 对照、数据与放行条件

| 次序 | 交付 | 预先固定的检查 | 无增益或证据不足时 |
| --- | --- | --- | --- |
| R0 基础可测量 | 同平均实际仓位解释对照；单独风险预测检验；公司行动数据适配 | 第五组误差披露且不可部署；预测损失与账户效用分开；长账户回放不跳过公司行动 | 保留诚实结果，不从九日工程样本读效果 |
| R1 成熟模板 | 固定部分调整；随后独立实现 Qlib TopkDropout 模板 | 两者不与排名保留带混称；固定参考版本、参数与交易边界；不新增撮合引擎 | 作为可选体验模板，无须声称提高收益 |
| R2 成本感知速度 | STRUCT 一致成本接口 + 低维选速，与固定速度及禁区比较 | 冻结信号、测试窗、授权与参数搜索预算；同平均仓位、风险及换手的必要对照；按日期块估计配对不确定性 | 相同换手下无改善则不推出“智能速度”；先做诊断/模板 |
| R3 年龄与规则暴露 | 先给带不确定性的诊断；再研究是否改变行动 | 时间戳与成熟标签；样本不足明确不给结论；黑盒预测不声称审过因子内部 | 保留信息展示，不转成自动退出或降仓 |
| R4 前向核验 | 冻结政策版本，平行纸面账户持续记录 | 漏记、受阻、失败与版本变更可见；事后均值匹配不进入可部署组 | 不因回放好看取消前向核验，也不把几个月观察当永久有效 |

所有课题分别报告：预测/校准质量；净收益与风险；成交额、费用、受阻和授权偏离。只改算法的增益与只降平均仓位、换手或偏低波风格的效果应分开说明。保留失败尝试，比较多个候选时披露搜索预算和多重比较。训练/验证/测试按时间分开，重叠收益标签跨边界清除；滚动拟合只能用已经到期的标签。

验收不能只看“回撤更小”：同等风险下更低成本、同等换手下更小目标跟踪误差、或成本压力下更稳定的净效用，均可作为事先声明的目标。独立样本外区间、不同起点和账户规模需覆盖；对照参数不能看完测试成绩再挑。若差异的不确定性大，就写证据不足。

## 这轮已知限制

现有 40 股引导数据不代表完整 A 股。2024–2025 原始股数回放在 2024-07-05 的持仓复权因子变化处停止；这是公司行动适配缺口，不能靠删股票、改起点、重置现金拼接成长期成绩。风险预测可以用复权收益单独检验，但不产生可执行组合净收益。先补数据/账本能力，再检验更复杂的学习政策。

普通 CPU 足以支持当前 Ridge 风险头和低维选速研究；完整数据加载、逐日成交及多次搜索可能比拟合更耗时，资源以实测为准。此路线不以 GPU、强化学习或大模型投委会为前置条件。
