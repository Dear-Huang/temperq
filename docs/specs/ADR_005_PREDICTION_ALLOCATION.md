# ADR 005：共享预测组合层与显式生产映射

日期：2026-10-23。状态：首轮软件实现与合成回放已有证据；连续效用训练未实现。

依据：[主 SPEC](E2E_RESEARCH_PLATFORM_SPEC.md) N02、[生命周期 ADR](ADR_004_ACCOUNT_LIFECYCLE.md)。复用文献 P04 的 CVXPYlayers 方法；风险/成本建模参考的项目和许可边界见 [调研](../research/E2E_RESEARCH_REVIEW_20261022.md)。没有复制 cvxportfolio 的 GPL 实现。

## 决策

1. `portfolio.prediction` 接收已冻结且可核验的 `e2e_prediction_v1` 日内预测归档，输出独立目标持仓。Ridge/GRU 使用相同风险、成本、账户协议及执行器；不将权重装入预测分数。
2. `portfolio.recipes` 只读决策时已可见的行情修订。风险用最近 60 个交易日日内小数收益、至少 20 个共同完整日期、固定 0.1 对角收缩及 `1e-8` 特征值下限；缺少任一资产历史则失败，不静默删除持仓。记录完整矩阵、日期、单位、条件数及源行哈希。
3. 流动性用历史正成交额的中位数。买入代理系数为 `(commission_bp + slippage_bp + impact_bp_at_full_adv * actual_equity / median_amount) / 10000`，卖出再加显式声明的税费。使用真实决策权益，不使用次日成交量；系数可用时间必须早于决策。这里的 ADV 名称对应中位数，不是算术平均。
4. 实际账户漂移权重决定交易代理；候选与已有持仓取并集。退出池持仓禁止增持、预测收益显式置零；仍需风险历史。未交收批次按执行时的已知可售资格约束；已知终止资产目标为零。约束冲突发出结构化失败，继续持有并计量市场损益。
5. v2 应收比例作为 DPP 标量参数，限制 `sum(w) <= 1 - receivable - min_cash`。现金和应收分别审计；不能把应收投入股票。
6. 每个决策保存 queued/started/target/explicit_failure，取消或异常时保存 failed_run/not_run 与运行失败。数据、源码在运行中变更则拒绝。结果冻结输入/配置/协议，并记录 Python、平台和数值依赖版本。
7. 策略路径生成的目标再次交给独立 `bench.targets` 回放，要求两条精确账户路径相同；全量验证器重新计算风险、成本、目标、失败台账与账户。默认需要同一实现和环境；`--inputs` 再核验原始路径及源归档。

## 数值边界与生产输出

SCS 的原始解可能含极小负权重。首次 strict_raw 合成运行中 B0/B1 各 29 次决策均被严格目标校验拒绝，失败产物保留在 `artifacts/allocation-demo-20261023-001/`，对应源码包保留在 `artifacts/releases/20261023-allocation-strict-source/`。这不是把负权重放宽为合法目标的理由。

生产方必须事先选择输出策略：

- `strict_raw`：原始解直接校验，拒绝非法权重。
- `highs_l1_projection_v1`：SciPy HiGHS LP 求距原始解最近的 L1 可行权重，使用相同上下界、预算和换手限制。最大单项改动不得超过配置容差，且容差上限 `1e-6`；过大则失败。保留原始解、生产解、改动及 LP 状态。没有等权/全现金回退，也不放松经济约束。

该映射发生在生产端；目标验证器不修复。CVXPYlayers 原始输出与其梯度仍单独验证；HiGHS 投影没有反向传播。N03 必须明确训练动作与生产动作的差异，不能把此路径标为全程可微。

## 代理诊断与限制

风险配方仅覆盖下一日日内区间；账户还包含旧持仓隔夜、公司行为和未成交，不能称已完整估计净权益路径风险。线性成本不包含精确最低佣金、手数与离散执行。显式卖出税率是配方声明，不是完整历史税制。

按日保留三种成本：决策意图代理、实际成交额代入同一系数的代理、精确账户费用，并分解：

```text
实际费用 - 意图代理 = (成交代理 - 意图代理) + (实际费用 - 成交代理)
```

另报意图/实际换手及目标到实际收盘权重 L1 差异。收盘差异包含价格漂移；意图换手以决策权益计量，实际换手以开盘权益计量，二者不是同一个分母。当前阈值是每日费用差/期初权益和换手差，不是相对成本准确性认证。

最终合成回放 `artifacts/allocation-demo-20261023-004/` 中，两模型均 29 个目标、无失败、无阈值超限；实际费用 250.0758 元，成交代理 68.3677 元，相对差约 265.78%。两模型实际成交路径相同，无模型优胜结论。该偏差须进入 N03 前置诊断与消融；不得因阈值未超限宣称代理已准确。

不支持本阶段以外的做空、杠杆、行业风险模型、跨日挂单或实盘券商。这里只完成 N02 首轮软件链路，不是 M3 训练或经济验收。运行入口见 [共享组合层](../PREDICTION_ALLOCATION.md)。
