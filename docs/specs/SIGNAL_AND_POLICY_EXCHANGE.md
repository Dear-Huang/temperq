# 入门模型、外部信号与政策交换

2026-10-23。第一版只提供数据和配置接口，不提供任意 Python 插件安装。

## 随包入门模型

`public40_lgbm_v1` 使用 BaoStock 公开日线，2021-01-04 至 2026-10-22，40 股声明名单。固定一组 LightGBM 配方，80 轮、种子 0，逐年样本外预测从 2022 年开始。最终拟合只使用标签已到期样本；数据截止与训练标签截止分别见随包 `distribution.json` 和 `final_model/meta.json`。

复现：先下载匹配的 `free_daily` 行情，运行 `scripts/build_starter_model.py --output <新的目录>`。脚本固定快照再训练，保留训练归档；每次构建是新尝试，不覆盖已发布版本。随包模型卡记录实际快照、配方、代码身份和文件哈希。不把包内模型宣称为全市场基准，当前股票名单存在历史选择局限。

包内仅含权重、配方、折记录和预测，无原始行情或账户。首次点击安装才复制到本地 runs；复制前后校验清单。使用的行情股票集合必须匹配，因为截面特征依赖股票池。更新模型需发布新版本，不替换旧账户权重。

## 外部预测 v1

通过 `/signals/import` 导入 CSV，不加载模型权重或执行代码。契约包含名称、外部模型版本、完整股票池、上海时区 15:30 决策、五日次日开盘到第 6 日开盘标签。非此口径拒绝，不自动猜测或转换。

CSV 四列：`code,decision_time,prediction,generated_at`。每个日期覆盖完整股票池，分数有限且证券日期唯一；两个时点含时区，声明生成时刻不晚于决策。未来决策拒绝接收。生成时间是外部来源自报，不认证上游没有泄漏；首次接收时间由平台单独记录。

信号 feed 采用完整快照及原子指针。相同记录重传幂等；旧分数或生成时点改动、补入旧日期或契约改变都拒绝，须建立新来源版本。使用该来源建立策略时冻结历史预测和契约，前向只读取后续追加记录。缺预测停止，不复制昨日排名，也不用最终模型代填；晚到记录不能洗成按时前向。原始外部模型训练截止未知，不以导入时间伪造训练截止。

与行情 feed 独立：BaoStock 自动更新只负责价格，不替外部来源产生预测。默认值、治理、相同平均仓位对照、执行与纸面账本使用相同路径。

## 政策模板 v1

导出只包含 schema、原默认值版本、政策预设、完整政策参数和固定信号要求。不带策略名称、现金、持仓、路径、模型或成绩。导入严格校验字段与参数，拒绝额外账户或可执行字段。

模板的完整参数视为用户明确选择，资金变化不会静默覆盖。用户可恢复预设，重新使用账户资金默认值；微调后冻结为自己的策略版本。记录原模板哈希，模板不携带“收益认证”。导出模板与导出完整冻结配置是两个入口，界面说明区别。

## 下一层扩展边界

| 扩展点 | 当前实现 | 后续可扩展的地方 |
| --- | --- | --- |
| 数据 | BaoStock / 原有 CSV feed；不可改写历史快照 | 新适配器仍输出同一行情、来源和日历契约 |
| 信号 | 平台训练模型、随包模型、外部 CSV 分数 feed | 外部工具可通过稳定文件契约供给；之后再设计鉴权 API，不执行未知权重代码 |
| 治理 | 校验后的政策 JSON 模板 | 新组件仍输出受授权约束的目标，不绕过账本 |
| 研究模型 / 自定义规则 | 原有研究配置与源码开发 | 尚无统一第三方插件安装，不宣称已经支持热插拔 |

本地 `signals/`、`policy_templates/` 与既有 data/runs 一样被 Git 忽略，并纳入发布检查的私人路径列表。
