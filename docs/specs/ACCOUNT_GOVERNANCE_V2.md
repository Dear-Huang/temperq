# 账户治理 v2：自带信号与按需调整

版本：0.1，2026-10-25。状态：**历史试验内核及规则阶段入口已实现；未开放新调度的纸面部署**。保留旧五日协议与已有账户身份，不迁移旧成绩。研究依据见 [窄域研究](../research/ACCOUNT_ACTION_RESEARCH_20261025.md)。

## 1. 交付对象

用户可以继续在 Qlib、聚宽或自己的程序中研究因子，将输出交给 TemperQ 做账户构建和治理。不要求先在本平台重新训练，不建设平台行情商店或因子商城。

| 用户输入 | 治理责任 | 当前状态 |
| --- | --- | --- |
| 单因子或综合得分、排名 | 明确方向，构建目标，再应用账户纪律 | 既有外部预测路径；新试验支持排名快照 |
| 已标定预期收益 | 目标构建，并检查额外调整的估计收益门槛 | 新试验已支持；校准记录为用户声明，不独立认证 |
| 目标权重 | 保留原策略权重，治理只约束允许的偏离 | 后续适配；本轮未实现导入 |
| 第三方策略源代码 | 依赖管理、隔离运行、输出标准契约 | 后续，不直接执行上传代码 |

因子值不是完整策略；原始因子的方向、组合和缺失处理需要明确。首版默认数值越大越优，多因子组合先由用户在源端完成。不能将任意单因子自动宣称为有校准收益的预测。

行情由用户提供或由其授权的数据源在本地更新。只有当日排名，没有历史信号与行情，就不能给出历史回测；只有信号、没有价格，也不能可靠估值或模拟成交。

## 2. 架构

```text
平台模型 / 用户外部信号
          ↓
信号快照：分数含义、版本、可用时点、数据截止、预测期限
          ↓
构建：持仓数、保留带、目标权重、现金与仓位约束
          ↓
调度授权：固定周期 / 允许周期外额外调整
          ↓
账户报价：决策日已知价格、整手、可卖数量、估计费用
          ↓
门槛：额度、冷却、方向、交易预算、估计收益余量
          ↓
冻结目标 → 下一可执行交易时点 → 实际成交审计 / 等待原因
```

“何时检查信号、何时允许调整、何时实际成交”分开。日频首版 15:30 决策，最早下一交易日开盘模拟执行；没有盘中能力。报价使用当日已知价格；实际次日开盘价、涨跌停及成交结果不得进入此前的授权判断。

模型、规则、部署、运行四阶段继续保留。第一阶段不强制训练；第二阶段集中治理。原页面不增加并列主导航或把研究模块包装成可部署成品。

## 3. 周期与授权

默认固定每 5 个交易日检查并向目标调整；目标与实际持仓相同，或受整手限制时可以没有成交，不是到点必然付费。

可选择“定期 + 允许额外调整”。原周期以回放首日为锚，额外调整不重置它。周期外事件是普通信号更新，不自动获得交易权限。强制风控属于另一类事件，不能借此绕开用户的买卖授权；实际持仓越界需单独提示，不将“不交易”称为安全。

| 参数 | 工程默认 | 含义 |
| --- | --- | --- |
| `period_sessions` | 5 | 固定检查周期，交易日计数 |
| `allow_between` | false | 周期外是否允许额外调整 |
| `max_extra_per_week` | 1 | 上海时区 ISO 自然周额度，不是滚动五日额度 |
| `min_sessions_between_extra` | 2 | 两次额外授权最少相隔的交易日数 |
| `extra_direction` | both | 可改为仅卖出或仅买入；按预计实际数量变化检查 |
| `extra_turnover_cap` | 0.5 | 单次预计买卖总额 / 决策时权益；不采用单边除二口径 |
| `cost_multiplier` | 1.5 | 成本压力倍数，不是已验证最优值或统计置信度 |
| `minimum_surplus_bp` | 5 | 附加收益门槛，工程假设，不是收益承诺 |
| `evaluation_horizon` | 5 | 收益门槛的预测期限，必须与信号一致 |

额外目标一经授权即消耗额度；真实次日受阻也不自动恢复额度或每日无限重试。普通周期授权不消耗额外次数；新自然周重置次数但不清除冷却记录。

缺周期外新信号则等待，不沿用昨日排名；固定检查日缺信号则检验受阻。新快照必须对应当前决策时刻；不把旧版本或更晚生成的数据改名回填。

## 4. 收益门槛的适用条件

只有 `score_kind=expected_return`，且声明校准版本、校准数据截止时刻、预测期限的信号，才能做收益与费用比较。校准数据必须早于当前决策；这种检查不能认证校准确实正确或没有别处泄漏。

排名或原始因子分数没有收益单位。无论数值变化多大，都返回 `UNCALIBRATED_SIGNAL`，不能解释成 bp。它们仍可进入普通周期的目标构建。

额外动作的初步估计：

```text
预计增量收益 bp = Σ(预计股数变化 × 当日已知价格 × 该股预期收益) / 当前权益 × 10000
所需收益 bp = 估计成本 bp × 成本倍数 + 附加门槛 bp
```

只有预计增量收益严格超过所需收益、且其他授权均满足，才产生额外目标。现金收益首版按零假设。涉及的旧持仓和新目标均需有收益预测，缺值不填零。

报价复用现有整手、最低佣金、按日税率、T+1 与可负担性引擎，假设价格不变且没有流动性阻碍。STRUCT 路径使用决策日可得的滞后估计；它仍不是未来真实冲击。部分交易不可行时拒绝额外动作，避免悄悄从“换仓”变成“只买不卖”。实际次日执行仍可能受阻，目标与成交分别记录。

这比较的是指定预测期限内“现在执行这个动作”相对不动的估计增量，不等于已经解决“等到下一个固定日会不会更好”的最优停止问题。没有相应训练与检验前，不使用该宣传。

## 5. 外部信号契约

CSV 五列：`code,decision_time,prediction,available_at,data_asof`。一行一股一天；同一天快照的可用时刻和数据截止一致；时间带时区。首版仍只接受 15:30 决策，不把更晚信号移到当天较早时点。

版本、分数含义、预测期限和可选校准身份由同一份契约填写，不要求每行重复。预期收益用小数：0.01 表示 1%，不是 1bp。原始分数默认仅用于排序。

下载模板包含原存档分数，但可用时间、数据截止留空，必须按真实来源记录补齐；不根据名义决策时刻伪造可用时间。快照内容、原 CSV、契约和数据身份随试验保存。用户声明与本平台实际接收时间不是同一回事。

本轮未实现源平台插件、权重 CSV 或通用策略代码加载，也没有提供新的数据授权。

## 6. 页面与记录

规则阶段底部“高级：调仓时机试验”进入：

`/strategies/{sid}/{vid}/timing`

选择历史信号、含义、版本、区间及是否允许周期外调整；其他参数折叠。主按钮只有“比较调仓规则”。结果先显示固定周期与当前时机规则的净收益、费用、实际仓位和换手，再按需展开每日决定及原因。

不将“成功回放”显示为“策略有效”。结果固定标识历史试验，尚无收益优势结论，不能直接开启新调度的纸面账户。原账户和冻结配置保持原样。

每次点击新建独立试验，保存成功或失败，不覆盖。路径为版本下的 `timing-experiments/{id}`，与旧 `evaluations` 分开，避免旧部署门槛把未验收的新引擎结果当作可部署证据。

首版原因码包括：`SCHEDULED`、`WAIT_PERIOD`、`WAIT_SIGNAL`、`EXTRA_LIMIT`、`COOLDOWN`、`UNCALIBRATED_SIGNAL`、`HORIZON_MISMATCH`、`INCOMPLETE_RETURN_FORECAST`、`NO_EXECUTABLE_CHANGE`、`QUOTE_INFEASIBLE`、`DIRECTION_NOT_AUTHORIZED`、`TURNOVER_BUDGET`、`INSUFFICIENT_ESTIMATED_SURPLUS`、`EXTRA_AUTHORIZED`。实际受阻继续使用成交引擎原因码，不与授权混淆。

## 7. 验收与后续门槛

已覆盖：默认守周期；关闭额外调整时与旧固定仓位引擎权益一致；额外决定下一交易日执行；额度、冷却、方向与预算；原始排名不得当收益；未来价格不改变先前目标；信号迟到拒绝；真实涨停阻止成交；导入到结果的 HTTP 流程及原版本身份保留。

当前回放只支持固定仓位方式，原始股数遇公司行动停止。GUI 首版限制 1MB、10000 行信号、252 个交易日；长任务和更大范围后续接作业队列。

进入纸面部署之前还必须完成：

1. 同平均实际仓位、同换手对照及日期块不确定性分析；未匹配时不得声称触发能力提高收益。
2. 校准方法的滚动样本外训练与有效期管理，收益标签与预测期限对齐；记录全部尝试。
3. 新调度的冻结身份、额度与冷却持久化、重启幂等、失败不部分追加、迟到信号记录和新旧账户并行前向。
4. 足够的市场数据检验与真实持仓用户试用。即使通过软件测试，仍不代表收益增量成立。

不为开放功能而降低现有证据标准。先证明这个小问题有用户愿意持续使用，再扩大模型和平台范围。
