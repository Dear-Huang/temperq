# 工作台体验：一条路径，逐步展开

2026-10-23。训练仍是主线，治理是重点；本文定义体验，不修改成交、费用、预测或版本身份。参数与执行边界沿用 [简单模式 SPEC](SIMPLE_MODE_SPEC.md)。内部定位不写进 README。

## 两类用户，共用一个工作台

不要求第一次打开的人先判断自己是“小白”还是“专家”。默认给一条明确路径，熟悉的人在同一页展开设置；两种显示读取和提交同一套参数。

| 用户当前需要 | 默认入口 | 进一步深入 |
| --- | --- | --- |
| 不知道从哪开始 | 工作台识别数据和模型是否已准备，给下一步 | 查看数据要求、添加 CSV 或本地来源 |
| 第一次训练 | 资金档位、模型、数据、名称；其余有默认值 | 股票池、预测期限、训练参数 |
| 把排名用于账户 | 政策模板、现金、名称，立即看到通俗解释 | 持仓、保留排名、仓位、风险、实际费用 |
| 研究自己的方法 | 参数搜索、修改清单、冻结配置导出 | 看每次决策、版本与历史/前向证据 |
| 每天回来使用 | 继续上次工作，运行状态和等待原因 | 展开历史对照，或据旧设置创建新版本 |

专业用户吸引力来自可控、可解释和可复现的工作流，不用参数数量装作更专业。小白的易用性来自可运行的默认路径和明确反馈，不隐藏实际限制。

## 当前实现

- `/start` 是启动入口：训练新模型与使用已有模型；优先显示已启用版本，并保留最新草稿入口。历史演示单独标识。
- 模型发现按训练身份去重，命名副本与存档不计作两个模型；隐藏的模型不通过存档重新出现。发现仅基于元数据，冻结时仍做完整校验。
- 统一“模型 → 政策 → 检验 → 运行”。训练页内部设置不再另称一套全流程。
- 训练默认展示核心项；研究范围按需展开。完成页先给“配置我的政策”，完整报告折叠。
- 没有兼容模型或行情源时说明缺什么、去哪里准备，禁用空列表的继续按钮。
- 政策即时说明：现金、目标只数、单票/总仓位上限、调整节奏与风险方式。全部来自当前实际输入，不单独维护一份展示默认值。
- 高级参数按选股、资金、风险、费用分组；支持中文名/参数名搜索。比例同时显示百分数，底层小数单位保持一致。
- 逐项显示相对模板的修改；隐藏不生效参数并明确已修改但不参与计算的情况。收起高级设置不会撤销填写。
- 切换模板若会覆盖微调，先让用户选择保留或替换。名称、现金、持仓文件保留。
- 历史检验前、检验后、运行中各有明确下一步；运行后默认收起历史对照，不把每日状态埋进长报告。

配置解释描述的是目标政策；它不能替代原始股数、整手、停牌、涨跌停和已有持仓约束下的决策回放。未训练的风险算法不因显示开关而获得“已经证明有效”的标签。

## 仍需要的产品能力

| 顺序 | 能力 | 用户得到什么 | 当前边界 |
| --- | --- | --- | --- |
| 1 | 数据准备、训练、政策、检验、运行的可恢复流程 | 失败后知道下一步，返回能继续 | 本轮打通界面与反馈；不重写下载和执行引擎 |
| 2 | 小白数据自动更新 | 每日运行不长期卡在等待行情 | 另行实现，不把“自动检查”写成“自动下载” |
| 3 | 可复现的官方模型目录 | 不训练也能选择一个模型开始 | 本轮未交付；页面不显示虚构的可下载模型 |
| 4 | 外部信号向导 | 专业用户带来自己的预测 | 体检入口不等于持续接入；仍需时点、期限、股票池、版本契约 |
| 5 | 公开扩展接口及示例 | 用户能接入方法并保留统一账本约束 | 尚无统一插件安装系统；先做一个完整扩展示例 |

上面第 2、3 项是达到成熟本地模型工具体验的能力缺口，单靠页面改版不能补齐。治理的技术增量仍需独立研究与公平对照；本轮增加的是理解、操作和复现能力。

## 如何判断体验是否更好

软件验收：同一设置展开/收起后值不变；模板覆盖不静默发生；页面说明与冻结 JSON 相符；真实训练任务能进入政策、检验和纸面历史演示；合成数据不能冒充真实前向；手机、平板无横向溢出。

实际试用至少找 2–3 位第一次使用的人，观察而不代操作：

1. 从干净安装找到数据准备入口，并解释数据为何需要时间覆盖。
2. 用默认设置训练，找到下一步；下载和训练等待时间单独记录。
3. 修改一项纪律，说出它改变的行为，再恢复默认。
4. 区分历史检验与前向记录，找到等待原因。
5. 专业用户复核配置与修改项，并从运行中的旧版本建立新版本。

记录每步完成率、误点、求助、用时及复述是否正确。数据、模型就绪后的配置目标是五分钟；尚未经过外部试用，不宣称已达到该目标。自动化通过也不证明真实用户觉得易懂。
