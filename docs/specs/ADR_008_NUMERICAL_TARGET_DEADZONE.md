# ADR 008：显式极小目标持仓规则

日期：2026-10-23。状态：实施与验收中。依赖：[ADR 007](ADR_007_DIFFERENTIABLE_PRODUCTION.md)、[N03 SPEC](N03_UTILITY_TRAINING_SPEC.md)。

## 证据与决策

既有合成效用 smoke 的 B2 连续账户中，54 笔成交额小于 1 元的成交合计约 1.49e-8 元，却收取 270 元最低佣金。许多原始目标为求解器产生的极小正数。精确整数执行不产生这些成交；训练环境不能靠删除费用假装一致。

新增独立策略版本 `torch_box_budget_turnover_dust_v1`，保留旧映射语义。先执行 ADR 007 的映射，再将 `lower==0` 且 `0<w<=dust_threshold` 的目标置零。首个工程参考值为权重 `1e-10`，须显式传入；上限为 `min(tolerance,1e-8)`。完整动作相对原始解的单项修正仍不得超过声明容差。

这是公开的数值尺度目标死区，不能判断小正数究竟是误差还是真实意图。阈值以权重计，不保证对应所有资本规模下的相同人民币数额；每次记录被抑制的权重和决策权益下的金额。该值用于软件诊断，不据既有测试收益调优，也不作为市场交易阈值推荐。

正数可售限制下界不抹掉，账本中的已有持仓不删除。目标归零若要求卖出已有极小持仓，仍按原执行/费用规则尝试卖出；停牌、交收和其他限制可以阻止成交。超出阈值的真实小仓位保留；外部用户提交的目标仍由严格验证器读取，不被此原生模型策略改写。

置零会降低股票预算，但可能增加相对实际持仓的卖出换手。最终复查全部边界和累计修正；新换手超过上限时失败，不重新混合出小正数、自动放宽上限或静默切回旧策略。额外行业等耦合约束仍不支持。

## 梯度与兼容

前向使用 `torch.where` 的实际目标，抑制分支对原始小正目标的局部导数为零，无 straight-through。零点、阈值和正下界切换处为非光滑/不连续边界，单列测试，不宣称唯一导数。阈值外沿用原映射梯度；全部零仓/零梯度是合法负结果。

训练与精确账户必须传同一策略、阈值和缓冲。配置、逐决策审计及 checkpoint 记录这些值；旧检查点若改用新策略，标为新的诊断，不覆盖旧产物。训练增益与规则变化分开：固定相同原始解做策略消融，固定相同 checkpoint 做闭环评价，新训练另列，不能把三者混为模型提升。

本机合成消融 `artifacts/utility-production-ablation-20261023-001/` 已完成：12 份相同原始解，两个固定 checkpoint。B2 两种规则的精确费用均为 39.8218 元，连续费用由 277.2737 降至 67.2736 元；B1 精确费用均为 72.7482 元，连续费用由 346.3199 降至 156.3201 元。四组比较资格仍全部为 false。该证据隔离的是此路径上的规则影响，不能推出新模型优势、普遍费用精度或真实交易增益；最终源码及回归以验证记录为准。

## 验收要求

- 阈值内外及等号、负原始解、正数下界、零预算、已持有小仓位和换手紧约束；检查完整修正量。
- 死区内为零导数、阈值外的方向导数、边界单列；经 GRU/组合层/账户的梯度与合法全现金训练。
- 相同状态下训练与精确动作相同；已有持仓不能凭空消失，合法卖出仍付费。
- 冻结原始解比较 strict_raw、HiGHS、旧 Tensor 和新 Tensor 的拒绝/修正；固定 checkpoint 比较两种 Tensor 闭环。
- 原费用失败案例保留，原权益/费用门槛不放宽；新案例即使减少数值微成交，也必须继续报告离散手数、漂移和最低费导致的剩余差异。
