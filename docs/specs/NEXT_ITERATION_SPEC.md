## 1. 方向与优先级

平台服务两条平等的研究路径：原始时点观测到预测，以及原始时点观测与账户状态到持仓、按净效用训练。因子可选，Ridge/LightGBM、自定义网络及外部训练循环继续接入同一独立评价体系。

首条决策训练路径保持为因果 OHLCV/amount 窗口 → 小型 GRU → 固定风险/成本配方的可微组合层 → 显式生产映射 → 连续账户效用。真实成交评价使用独立原始股数账户。首轮优化优先解决执行近似、选择可靠性和证据完整性，再开展同预算模型研究。

首版范围仍是 A 股日频、多头、无杠杆。公告多模态、基础模型、RL、可学习风险/成本模型及优化后端加速各自立项；引入条件是现有链路已满足对应验收门槛，并有受控实验支持。

## 3. R01：执行误差逐日归因

对应 N03-T5/G0。先固定已有 B1/B2 checkpoint、源数据、初始状态、原始求解配置、生产规则和门槛，不训练。

1. 同时保留连续账户自身状态闭环、精确账户自身状态闭环和冻结连续动作的精确回放。固定动作诊断按协议重新绑定状态身份，不能冒充原始策略提交。
2. 从已有整数完整、分数份额与费用诊断扩展，逐项考察整数手、最低佣金、资金可买数量、交收、市场限制、价格漂移和反馈。每个反事实仅改变计划声明的机制，并核验实际成交，而不只比较目标权重。
3. 成本分别报告意图代理、实际成交上的代理和精确费用；保留税费、佣金、最低费溢价、滑点及冲击分项。核对 `actual-intended = (filled-intended)+(actual-filled)`，分母为零沿用显式 null 规则。
4. 归因表固定机制启用顺序，逐步差额和等于端点总差，另报残差与交互限制。顺序分解不宣称是唯一因果贡献；关键交互至少补做整数手 × 最低佣金的配对场景。
5. 保存首个状态/成交分叉、后续动作反馈，以及现金、股数、交收批次、逐事件应收日程、费用、换手、净权益、未成交和违约。采用 ADR 009 的决策前/收盘后比较语义。

关闭条件：手算夹具与整数完整参考在预声明容差内；实际样例的总差可重算且未解释残差有明确标记；超限原因与适用范围可查。诊断框架完成不自动使分数份额路径合格。不能调宽旧阈值、删除小额费用或挑全现金样本来关闭误差。

产物：冻结计划、逐日/逐笔差异表、成本桥接表、场景矩阵、首分叉记录和可重算摘要；全体失败场景保留。

## 4. R02：模型选择可靠性审查

对应 N03-T3/T5/G2。现行 `e2e_utility_v1` 仍按连续 validation loss 严格改善选 epoch，平分保留较早者；epoch 0 仅为控制。不改写历史模型的选择理由。

下一轮先增加**诊断**：保存每个完整 epoch 的候选身份，在同一内层 validation 上无梯度运行精确闭环，并与连续验证比较净效用、费用、风险、换手、可行性和排序。检查连续损失改善是否主要来自代理误差，报告排名反转与缺失/失败候选；单候选或全平分时排序统计为空并说明原因。

精确验证数据、事件和执行反馈必须不晚于该折 `selection_cutoff`；外层 test 不参与 epoch、门槛、成本、初始状态或生产规则选择。诊断预算计入训练/搜索总账，不能事后只补算看好的候选。

当前决定仅加入审查，不隐式引入新选择策略。若证据支持改为精确验证选模或增加资格门槛，须先立 ADR 与新配置版本，固定目标公式、最小化方向、epoch 0 是否参与、平分规则、失败行为、完整预算及 checkpoint 保存语义。配置校验器在实现前拒绝该能力。

关闭条件：已知代理排序反转夹具能被识别；改动外层 test 不能改变已选 checkpoint；重算能核对候选身份与排序；原 v1 选择结果和同轮权重/优化器/RNG 一致性保持可验证。审查不能宣称解决了执行近似本身。

## 5. R03：训练图、因果性与阶段审查

对应 N03-T1–T6/G0–G3。建立逐条需求矩阵，每条包含代码入口、用例/命令、输入和实现身份、实际结果、证据路径及剩余限制。状态使用已验证、部分验证、未验证、不适用；不适用须有范围理由。

重点补核实际 GRU → 求解 → 生产映射 → 跨日账户 → 效用计算图；包括光滑方向导数的步长扫描、活跃集/零交易/最低费/整数边界、detach 的收益分母、冻结参数、合法零梯度、最佳轮状态和取消/超时。

未来信息扰动分两类断言：更改决策后价格、流动性或事件不改变此前观测、配方、约束与动作；执行揭示后可以改变后续账户和动作。不能要求未来成交变化后整段策略仍保持不变。

实现验收按以下顺序交付：

1. 使用确实依赖输入的原生 GRU 与非全现金账户，分别扰动未来价格、流动性、事件、迟修订及其组合；在连续/精确两账户核对决策前完整输入和求解/生产审计，并验证信息可用后能实际影响后续预测。
2. 缺历史、后端求解失败、生产映射拒绝和非有限梯度分别在首轮/完成一轮后注入，核对 `utility_training_failure_v1` 的轮次/阶段与 `decision_policy_error_v1` 的决策上下文；已完成候选与 not_run 不丢失。
3. 费用明细显式采用 v2，手算核对 CNY、固定期初权益 bp、本笔成交额 bp、零分母与全部桥接残差；旧 v1 默认保持兼容。用当前 checkpoint 运行并重算一份正式诊断，才关闭展示证据缺口。
4. 汇总 ADR 007 场景到实际用例及当前完整回归；以当前核心重放原 N02 固定目标。源码重算、训练重跑及导出安装分别记录，旧包不能代表新核心。
5. 最后补独立进程资源测量：资产池/episode/BPTT 参数事先固定、真实预测预训练来源可核验，记录时间、峰值 RSS 与失败率。未实测的规模不列为支持能力；`detach_every` 不等于内存随 K 有界。

原生训练错误中止与外层精确诊断的显式失败续持分别审查。后者按 ADR 011 显式版本启用；新增诊断字段本身不构成验收，G0-06 仍须当前核心用例和正式运行证据。当前证据和具体剩余项以阶段矩阵为唯一交接入口。

## 6. R04：冻结同预算研究

对应 N04，依赖 R01–R03 的阶段审查与待研究配置的适用资格。先使用开发数据冻结计划，再运行新的外层评价；已看过的区间继续标为开发数据。

**R04-D 开发期诊断**：E16 的 64/128 资产组梯度仅约 `1e-13`–`1e-11`，不能由运行成功推定学习有效。先固定来源/账户/配方，在开发数据核查收益头与费用量纲、最优解活跃约束、生产映射的动作敏感度及求解容差；用预声明步长的方向扰动比较实际目标/效用变化与反传，在分母接近零时保留绝对误差、相对误差置 null，边界单列。开发诊断 `artifacts/r04-d-diagnostic-20261023-001.json` 已显示 64/128 资产大部分原始权重处于下界，`±1e-4` 预测偏移的动作变化约 `1e-10`–`1e-9`，`+1e-3` 才出现明显活跃集跳变；这只是历史核心的数值诊断，不是经济结果。微小梯度可能来自真实约束也可能受数值误差影响，未经诊断不定因。若修改归一化、预算、目标或成本，建立新探索身份、再冻结研究，不回写 E16、不强迫交易或抬高成本制造梯度，也不以训练敏感度代替市场优势。此项不追溯改变 R03-R 的资源验收。

| 对照 | 要回答的问题 | 必须固定的条件 |
| --- | --- | --- |
| B0 Ridge/LightGBM、B1 预测 GRU、B2 效用 GRU | 树模型、表示与决策训练分别有什么证据 | 样本资格、收益时段、折、账户、组合层、风险/成本、生产映射、dtype 控制和训练/搜索预算 |
| encoder 冻结/可训练 × 预测/效用目标 | 增益来自哪里 | 同一预训练来源、共同可训练头、冻结范围与各格完整预算 |
| 成本、流动性、资金和约束压力 | 效果在哪些边界消失 | 压力场景与主/次指标事先冻结，保留不交易和冻结持股控制 |

至少三个预声明 seed 和明确滚动折；同时记录实际计算时长、搜索次数与失败，不以相同 epoch 数代替相同预算。树模型优先考察历史验证选轮数、正则化、标签/样本权重、缺失处理和特征消融，不能事后给单一模型额外搜索。

主要指标使用独立精确账户净效用/收益及风险成本指标。比较采用日期配对与块推断；块长及其敏感性、主假设、多重比较处理和最小有效样本在计划冻结。重叠折的测试日期有预声明去重/聚合规则；seed 不当作独立市场样本，辅助预测均值不当作集成账户。

全部 trial、失败日期和负结果纳入总账。外层超限/失败必须按冻结规则报告；不能删除不合格日期后只汇总成功子集。B2 不胜出也是可交付研究结论。合成样本只能关闭机制验证，不能建立 alpha 结论。

## 7. R05：专业扩展与发布

专业用户可通过版本化数据/输出契约使用自有 encoder、loss、allocator、folds 和训练循环；CLI、worker、网站复用核心逻辑。适配器声明模态、动态资产池、输出类型、设备、随机性、恢复粒度和支持的账户约束。未知/不支持能力显式拒绝，不自动转成另一任务。

不强制专业用户使用平台因子、GRU 或 GUI。自定义代码在用户受信任环境执行；公共网站接收元信息与证据链接，任意仓库代码的远程执行不在首版范围。新接口按实际专业工作流用例验收，再扩 GUI。

对外发布按 N05 分开验收：

| 层级 | 关闭证据 |
| --- | --- |
| 可上传 GitHub 的源码 | 发布文件/凭据扫描、依赖与许可、示例、源码身份、仓库内文档链接、可追溯验证摘要；本地 artifacts 不当作读者自动拥有的公开证据 |
| 可复现研究版本 | 实际 Linux 干净环境安装/运行、获授权可分发样本或标识清楚的合成样本、完整命令、模型/数据卡、非实现者复现与差异记录 |
| 服务器部署 | 实际配置/域名、镜像或依赖身份、持久化/迁移、健康检查、重启、备份恢复及日志结果；密钥不入库 |
| 市场效用主张 | 数据授权与 PIT/资产池/公司行为证据、完整公平研究、方案冻结后的未见数据及容量敏感性 |
