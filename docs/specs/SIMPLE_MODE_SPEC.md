# 简单模式与全流程 SPEC

版本：0.2，2026-10-23。根据 v0.1 草案、官方文档核查和首个纵向实现修订。当前范围与后续目标分列；不改变已有冻结纸面账户。方法见 [治理 SPEC](GOVERNANCE_SPEC.md)，依据见 [实施核查](../research/SIMPLE_MODE_IMPLEMENTATION_REVIEW_20261023.md)。

## 1. 目标与界面

这是本地可视化量化训练平台的一条完整使用路径：训练或选择模型，按自己的持仓与观念配置治理，检验后持续纸面观察。训练是核心能力，治理是重点深化环节；评价帮助理解结果，不替代训练平台的主线。预设与高级展开让不懂参数的人先用默认值，懂的人可以修改和导出实际配置。

默认核心设置加一个“高级设置”展开区，暂不做三种独立界面模式。展开与收起不改变计算。用户体验目标是数据、模型就绪后五分钟内完成配置并启用纸面观察，且能解释改了什么；自动化测试不代替普通用户可用性测试。

| 默认可见 | 高级展开 | 固定口径 |
| --- | --- | --- |
| 信号、数据源、名称、现金、行为预设 | 初始持仓 CSV、只数、排名保留带、仓位/现金、调整速度、风险方式与目标、佣金及滑点压力 | 五日节奏、收盘决策/下一开市日开盘执行、T+1、申报数量、按日期适用的税率及市场规则 |

固定仓位时风险目标不参与计算，页面隐藏，导出列入 `inactive`。不使用“稳健 10%”等可能被误读为亏损保证的名称。佣金和最低佣金可以填写实际券商口径。

## 2. 一个策略，四步建立

启动入口 `/start`，按已有数据、模型与策略显示下一步；`/strategies` 保留完整策略列表。默认路径、专业参数展开和软件验收见 [工作台体验](WORKBENCH_EXPERIENCE.md)。原训练、评价、纸面账户和治理实验继续可用，旧账户不自动迁移。

| 步骤 | 用户理解什么 | 当前实现 |
| --- | --- | --- |
| ① 选择信号 | 谁给股票打分，后续数据从哪来 | 已有训练模型和数据源；训练完成页可进入 |
| ② 配置政策 | 排名之后怎么买、买多少 | 选预设、填现金；高级区微调；冻结完整设置 |
| ③ 历史检验 | 过去这样做会怎样，与什么比 | 存档逐期预测回放；同信号、风险方式和授权的立即调整对照；失败也保留 |
| ④ 纸面运行 | 启用后如何每日记录 | 固定模型推理新行情；同一治理与成交函数记账；手动或明确开启每日检查 |

运行后默认日常面板，显示启用日、最近记账日、现金权益、建议日/计划执行日、等待或阻塞原因。部署指本地纸面运行，不连接券商。

自动检查只在工作台存活时于 17:30 后每天尝试一次，读取已更新数据源，当前不自动抓行情。默认关闭，重启同日去重；补数据后可手动重试。电脑关闭后的旧日期重建不能冒充按时前向。

## 3. 配置与身份

底层分信号规格、政策预设、策略版本、检验证据、运行实例五个职责。检验和运行读取同一份冻结配置。

- `GovernanceConfig` 为数值权威类型，`policy.Policy` 校验风险模式、拒绝未知字段和布尔数字；导出 `/policy-schema.json`，UI 元数据单独提供中文名称、单位、解释、适用条件。
- 工程默认 → 预设覆盖 → 用户覆盖 → 校验/冻结。保存默认版本、预设版本、逐项来源、相对预设修改、不生效字段。
- 每版复制模型与存档预测，绑定任务、数据源、账户初值、协议、费用和执行实现哈希。
- 绑定可追加的 feed 指针，每条账本记录保留实际使用的快照身份。
- 修改建立新版本，旧设置和账户不覆盖。执行实现变化停止旧版本追加；旧报告仍可读，可据旧配置建立新版本。
- 本轮只登记治理纵向路径所需参数，不宣称已统一全部训练、Bench、B1/B2 参数。

## 4. 预设与默认值

| 项目 | 默认 / 预设 | 性质 |
| --- | --- | --- |
| 直接调整 | 固定仓位、速度 1 | 默认预设、简单对照 |
| 分步靠近目标 | 固定仓位、速度 0.5 | 自有研究机制转化；0.5 是待验证的工程选择 |
| 波动目标 | EWMA、年化目标 0.15、速度 1 | 成熟风险基线，不是最大回撤保证 |
| 初始现金 | 100,000 元，可改 | 示例值，不替用户判断应投资多少 |
| 只数 / 保留排名 / 单票上限 | 10 / 15 / 0.1 | 工程默认，不保证每只实际都能买到 |
| 总仓位上限 / 最低现金 | 1 / 0 | 目标限制；实际可能因受阻/跳空偏离 |
| 单边佣金 / 最低佣金 | 3 bp / 5 元 | 按实际券商修改 |
| 滑点压力 | 0 bp | 未加人为压力，不代表真实价差与冲击为零 |
| 自动检查 | 关闭 | 用户明确启用 |

不把资金档位、风险偏好或 1.5 倍排名带说成已证明的最优值。启用前按现金、参考原价、板块最小申报量及费用检查：全部目标不可买且无初始持仓时阻止启用。部分不可买和开盘受阻仍需可见。

## 5. 自有研究的首个入口

`w_partial = (1-a) × w_drift + a × w_immediate`

当前只对选中的篮子平滑；退出选择范围的目标归零，硬限制优先，单票截断，总量超授权则向下缩放，余款现金。支持 `0 < a ≤ 1`，不把永不交易当获胜政策。论文月频系数不能照搬成五日最优系数。

对照报告列两条路径的费用、交易额/权益、回撤、收益与平均实际仓位。只改变速度不保证实际敞口/风险相等，少交易和低仓位不能直接叫作 alpha。独立五组治理实验继续保留 ML 同平均实际仓位事后解释组，该组不可部署。

每个决定展示漂移权重、立即目标、分步/限制后目标和模拟成交，保留原因、受阻及实际约束偏离。成本感知选速、STRUCT 入账、信号年龄和规则暴露按 [研究路线](../research/GOVERNANCE_RESEARCH_ROADMAP_20261023.md) 单独验证。

## 6. 三类结论分别展示

| 结论 | 当前能说什么 | 不能代替什么 |
| --- | --- | --- |
| 可运行性 | 信号、日历、参数和参考数量条件通过 / 阻塞；列检查范围 | 不保证开盘成交，不代表独立证明上游无泄漏 |
| 经济增量 | 指定路径的费用、交易规模、仓位和风险/收益差；当前标证据不足 | 不给未来收益总绿灯，不据此建议加仓 |
| 运行健康 | 等待数据、已记录到某日、阻塞；按时纸面/迟到重建/历史分别计数 | 日历/数据故障不能用统计不确定掩盖 |

失败检验和本地可见尝试次数保留，不覆盖别处尝试或人为删除。不承诺“再等 M 天必有结论”。已计佣金、按日印花税及自填滑点压力；STRUCT 未入账，价差与冲击未标定。

## 7. 运行与验收

同一治理和原始股数成交函数用于历史及运行。运行用 SQLite 事务和日期主键，重试不重复记账；确定性重建并核对已记前缀后追加。该实现优先可审计性，长账户有重建成本，不承诺多年全 A 秒级回放。

最终模型禁止回填训练截止前历史；历史演示只读存档当期预测。15:30 前不消费当日收盘。下个执行日取权威交易日历；行情缺口不得删除日期压缩；持仓公司行动不支持则停止并回滚，不拼接净值。初始持仓保留数量和可卖数量。

验收覆盖：类型/条件生效、冻结/版本保留、检验运行路径一致、前视边界、不可买账户、交易日历、公司行动回滚、篡改阻塞、幂等重试、自动检查、真实浏览器四步和桌面/平板/手机。

## 8. 后续版本

官方预训练模型与复现说明；外部预测契约与持续供给；自动行情更新；公司行动生命周期；普通用户独立试用；更多统计对照；STRUCT 与低维学习选速。当前界面不把这些未来能力显示成已可选。

B2、强化学习、大模型投委会、社区比较不作为本轮主流程验收条件。

## 9. 开放扩展点（接口设计，尚未实施插件系统）

保持开源、本机运行，用户能在同一平台扩展成熟范式或新成果。首轮先明确四类边界，不为插件目录或任意代码执行增加发布依赖。

| 扩展点 | 输入 / 输出契约 | 必须保留的检查 |
| --- | --- | --- |
| 数据适配器 | 授权数据 → 带来源、时点、交易日历及身份的行情快照 | 单位、证券、缺失、历史修订和公告可用时间 |
| 信号来源 | 冻结模型及当时可用输入 → 带决策时点、期限、股票池和版本的分数 | 模型/输入签名、可用时点；存档预测与未来持续供给分开 |
| 治理模板 / 组件 | 持仓、现金、分数、授权 → 参数预设或目标提案与原因 | 目标仍过授权和数量检查，不绕过统一成交账本 |
| 用户规则 | 已声明的字段和受限公式 → 特征、过滤条件或约束 | 只能看过去；明确是供模型参考还是必须执行；修改要版本化 |

每种扩展声明 `id`、版本、支持的市场/任务、依赖与输入输出格式。模型、规则与模板的经济改动进入策略版本；第三方代码需要用户明确安装，上传数据不触发任意 Python 执行。原有 CSV 因子/预测入口不等于已经具备统一插件体系。市场规则包预留多市场扩展，当前交易执行仍只支持已声明的 A 股范围。
