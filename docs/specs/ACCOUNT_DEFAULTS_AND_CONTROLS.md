# 账户默认值、仓位对照与每日更新

2026-10-23。适用于本次更新后建立的策略版本。

## 资金默认值

策略与训练共用 `scenario.derive()` 的资金档位。现金起步按现金确定档位；有初始持仓时，加上所选行情源最新收盘价估值，并冻结参考日、快照与估值口径。此参考权益只用于配置默认值，不替换历史回放首日估值。

默认持仓数取档位设置，单票上限为 `1 / n_hold`，保留排名为 `ceil(1.5 * n_hold)`。例如 500 万参考权益对应 30 只、单票上限约 3.33%、保留排名 45。后两个关系是工程默认，不是盈利最优参数。界面预览与后端冻结使用同一套推导；用户明确改动的值优先，切换显示不改变参数。

资金档位的流动性门槛显示为训练参考，**当前治理没有另外按该门槛筛股或限制成交量**，不得表述为“大资金一定买得进”。

## 三组历史对照

1. 当前政策。
2. 同信号、同授权、同风险方式的立即调整，速度设为 1。
3. 同信号、同授权、固定目标仓位的立即调整，校准其平均实际收盘仓位接近当前政策。初始现金、持仓和日历均相同。

第三组复用治理实验的 `constant_exposure`，只按仓位误差挑选参数，不根据收益挑选。匹配数量不含初始状态，容差为 0.2 个百分点，最多搜索 12 次；不满足容差就明确显示失败及误差。校准使用完整历史，属于事后解释，不能部署，也不证明 alpha 或消除全部风险差异。风险控制政策的第三组还改变了风险方式，不能解读为只比较调整速度。

建仓观察期在回放前规定：按理想静态目标剩余差距不超过 5%，确定 `K = ceil(log(.05) / log(1-speed))` 个五交易日周期；速度 1 取一个周期。前 `5K` 段日收益为建仓观察期，其余为后段，所有组使用同一边界。后段不保证达到稳态；无样本明确显示，不把建仓现金效果当作稳定换手收益。

## 每日更新

自动运行仍须用户开启，并保持本地工作台运行。17:30 后每天尝试一次，重启不重复自动尝试；失败后可手动重试。

- BaoStock 可更新数据源：使用原有股票集合，先下载并校验全体股票与日历，再原子发布快照，最后记账。当日下载只有在 17:30 后开放；普通首次下载仍截止昨天。
- 已覆盖的休市日或已完成快照：无需联网。
- CSV 等其他来源：不替换数据源，读取用户更新的数据，缺数据继续等待。
- 下载失败或数据不齐：显示受阻，不调用记账，不发布半份数据；既有记录保留。
- 晚到记录仍按既有规则标记重建，不冒充按时前向。

本次修改会触发策略工作区的实现身份检查。旧工作区版本不能静默延续新算法，需建立新版本；历史记录保留。独立旧纸面账户的执行源码未修改，不迁移或改写其前向记录。
