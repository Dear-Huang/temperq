# 部署看板 v1

2026-10-23。第四步“部署”是开启本地纸面运行，并在同一个冻结策略版本下持续跟踪。训练、政策、检验仍是前面三步；看板不另建一套计算或账户。

## 用户如何进入

完成历史检验后，点击“开启纸面观察”，进入该版本的部署看板。以后从工作台“继续上次的工作”或“我的策略”直接回来。历史演示也可以打开看板，但全页标注历史演示，按时纸面记录为零。

尚未启用或尚无记录时显示空状态，不使用回测结果或参考资金补画一条曲线。旧版本仍可查看；实现身份不一致时显示受阻，按原有机制要求创建新版本。

## 两层信息密度

- **总览**：账户指标、净值、资金分布、持仓、最近决策、回撤与仓位、运行控制。先回答今天是否有事要处理，再看详细信息。
- **专业多窗**：在总览基础上增加模拟成交与受阻、费用分解、记录质量。深色终端、对齐数字、多栏窗口；手机改为纵向排列，图表按容器宽度重画，保留可读刻度。
- 支持选择显示窗口、恢复默认、全屏、持仓代码筛选。显示偏好保存在本机浏览器，按策略版本隔离，不影响政策计算；运行控制常驻。

## 指标与数据口径

看板只读取已有账本，不下载、不推理、不回放、不因刷新自动记账。

| 窗口 | 口径 |
| --- | --- |
| 总权益、现金、实际仓位 | 最后一条账户记录，明确最后记账日期 |
| 最近一日盈亏 | 相邻两条权益之差，费用已在权益里扣除；首条记录不显示日盈亏 |
| 路径累计收益 | 最后权益 / 首条权益 − 1；包含初始持仓，不能用初始现金作分母 |
| 净值 | 以全部账户路径首条记录归一为 1；20 日、60 日只改变显示范围，不重新选择起算点 |
| 最大回撤 | 全部已记录权益相对运行高点；缩短图表区间不重写历史高点 |
| 持仓 | 账本估值、持有量、可卖量、市值和实际权重；相邻估值变化不称持仓浮盈 |
| 最近决策 | 最近目标与当前实际持仓比较，包括价格漂移；不是待执行订单。是否已有执行日记录与是否成交分开表述 |
| 费用 | 累计佣金、印花税、STRUCT 半价差估计及额外压力，保留冻结成本口径；不称完整实际成交成本 |
| 成交与受阻 | 最近 100 条指令结果，保留零成交、部分成交和原因；完整历史可导出 |
| 记录质量 | 按时纸面、迟到重建、历史演示分开计数。混有迟到的曲线称账户路径，不称纯前向成绩 |

无实时行情、新闻、盘口或券商连接时，不放虚构的行情流、实时灯或订单窗口。样本不足时不以年化夏普或收益打分制造结论。

## 持续运行

看板每 30 秒读取一次账本快照；隐藏标签页时暂停轮询，回来后读取。同步时间和最后记账日分开显示。断连保留上次成功记录，明确说明未能读取新数据；恢复后正常更新，读取失败不删除旧曲线。

“检查行情并记账”提交原有独立任务，完成后返回看板；BaoStock 的完整下载校验与账本保护沿用原实现。“每日检查”由用户明确开启，工作台运行时在 17:30 后每日尝试一次。关闭看板不等于关闭工作台；关机后仍不会自动运行。

POST 操作沿用本地请求与 token 校验；展示接口不返回数据源路径字段、完整账户配置或模型文件。图表、字体和脚本均为本地资产，不依赖外部图表 CDN。

## 验收

单元和接口验证包括权益分母、回撤、费用、空记录、范围标签、HTML 转义、只读轮询、CSRF 及独立任务回跳。浏览器验收通过真实隔离账本检查窗口切换、区间、键盘曲线查询、搜索、断网恢复、显示偏好、自动检查切换与手动任务；不得将软件演示认作投资效果证据。
