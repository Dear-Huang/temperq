# ADR 002：时点序列训练与既有运行系统接入

日期：2026-10-23。状态：实施中；验收结果见 [实施记录](../E2E_IMPLEMENTATION.md)。

## 任务与兼容

M1 使用独立 `e2e_prediction_v1` 配置与 `cn_predict_intraday_v1` 任务，输出仍为标准分数；标签是次日开盘至收盘收益。`cn_alloc_daily_v1` 保留为目标持仓任务，不能把预测运行标为已经完成直接持仓。原年度训练配置、哈希与五日 Bench 不重新解释。

复用 `qwb run`、worker、不可覆盖的运行归档、失败保留与摘要导出。序列模型按折保存 checkpoint，只声明历史滚动预测版本；没有额外最终重拟合时不生成面向未来的模型版本。原五日 Bench 对新任务明确拒绝，M2 再提供匹配日频任务的独立账户入口。

## 数据与标签

新数据入口是 `pit_numeric_v1` bundle：`manifest.json`、显式交易日历 `calendar.json`、带 `available_time/revision` 的 `bars.parquet` 与逐日 `universe.parquet`。日线完整 OHLCV 的可用时间不得早于当日收盘；资产池每个决策日必须有可见的声明，不能从未来行情是否存在反推资格。缺失、短历史和不在池中的记录有覆盖审计。

旧快照没有可核实的可用时间时，不能补一个收盘时间冒充供应商时点证据。合成样本可以声明生成规则并验证软件，始终标记 `SYNTHETIC_ONLY`；市场数据即使字段齐全，也只标记未经外部认证的开发诊断。

训练标签从执行日原始开盘/收盘构造，并在每个折的训练、选择截止时点分别选取当时可见修订。不能用数据末尾的最终修订标签训练过去模型。最终评价标签另按预声明 `evaluation_asof` 读取；无可用标签的预测仍保留，不因未来难样本消失。输入文件在读取前后及运行结束重复核对哈希，变更导致失败。

## 模型、预算与产物

GRU 采用窗口值与缺失掩码、收益 MSE、历史验证早停，不在验证段重新拟合。标签仅由训练样本拟合均值/标准差（尺度下限 `1e-8`），供网络优化使用；预测、历史验证与报告均还原为原始收益单位。首次合成流程中未标准化的网络初始值与日收益相差多个量级，因此另冻结新版代码验证数值尺度；旧结果保留，不据此选择经济赢家。checkpoint schema 2 保存变换；schema 1 按原始输出语义加载。

Ridge 因子基线使用相同窗口、样本、标签和时间折；特征标准化只拟合训练样本。基线输入与模型同时变化，不能将差异全部归因为表示学习。两者分别记录训练预算，参数量和算力并非天然相等。

运行开始前冻结折、种子与配置，并预建全部训练尝试；失败、取消和未执行项保留。内存样本上限与每次训练时间上限是显式资源边界，超限失败，不静默抽样或输出部分成功。

最低产物为原有必需文件、数据/观察身份、逐日覆盖、逐折模型和训练记录、完整尝试台账、种子预测与集成预测。模型产物必须可以无任意 pickle 代码执行地重载并复现预测。窗口/标签/资产池的未来扰动、月周折、失败保留、归档校验与 CLI/worker 都需验收。

M1 接通不能替代 M2 的实际账户、M3 的连续净效用训练或 M4 的冻结对照。
