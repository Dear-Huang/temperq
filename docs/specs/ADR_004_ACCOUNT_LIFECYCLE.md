# ADR 004：公司行为、应收资产与账户版本

日期：2026-10-23。状态：N01 首轮实现；验证结果见 [实施记录](../E2E_IMPLEMENTATION.md)。本 ADR 扩展 [ADR 003](ADR_003_TARGET_BENCH.md)，不改写 v1 结果。

## 版本与预算

- `target_protocol_v1`、`account_state_v1`、`target_weights_v1` 和 `target_submission_v1` 继续使用原语义，v1 公司行为必须为空。
- 新协议 `target_protocol_v2` 指定执行模型 `raw_share_lifecycle_v2`，要求 `account_state_v2` 与 `target_submission_v2`。目标为 `target_weights_v2` 或原结构的显式 `decision_failure_v1`；错误版本组合拒绝。
- `account_state_v2` 在原字段上增加不可变 `entitlements` 和 `processed_events`。分红登记权利尚不计权益；已确认应收计入权益，不计可用现金。净权益为现金、原始股数市值及已确认应收之和。
- `target_weights_v2` 增加 `receivable_weight`，必须等于决策时实际应收/净权益；股票、现金、应收意向占比合计为 1。不得把应收重新分配为现金，v1 目标不能用于 v2 账户。
- 目标仍是意向，按执行开盘总权益定量，买入必须由实际现金支付。决策到执行之间发生的除权/支付会改变可交易预算，不能通过重新归一化目标隐藏差异；保留目标、实际比例与未成交原因。
- 状态身份包含权利、已处理事件、现金、原始股数、交收和估值。集合按身份排序后哈希；旧版字段和身份算法不增加新字段。

## 事件及时间线

`corporate_actions` 为显式列表，每项严格检查字段，公共字段为 `event_id/asset_id/available_at/kind`。事件 ID 不得重复或包含阶段分隔符 `:`。

| kind | 额外字段 | 语义 |
| --- | --- | --- |
| `dividend` | `record_at/ex_at/pay_at/gross_per_share/withholding_per_share/ex_price_adjustment/tax_treatment` | 按登记时总股数确定权利，含当日已买但未交收股份；除权确认税后应收，支付时转现金 |
| `split` | `effective_at/numerator/denominator/fractional_policy` | 整数比例同时调整总股数、可售、各未交收批次及参考价格；批次交收时间不变 |
| `terminal` | `effective_at/settle_at/amount_per_share/valuation_basis` | 原始股份转为显式终止索赔权，按给定金额减记或重估；结算前不产生可用现金 |

日频执行模型只处理声明交易日 09:00 的除权/支付/拆股/终止事件，以及 15:00 收盘后的登记，随后在 15:30 决策；区间内其他事件时间明确拒绝，不四舍五入到交易日。初始状态之前的事件需提供一致的阶段历史及存续权利；未来未发生阶段可以留到后续协议。

同一时点按拆股、除权、支付、终止估值、终止结算的顺序处理，按事件 ID 确定同类顺序。同刻确认和支付在开盘前全部处理，不让应付款跨过账户决策或执行边界。收盘登记在当日成交及估值之后，因此登记后的出售不取消已经确定的权利，除权后买入也不获得过去的登记权利。

`gross_per_share/withholding_per_share` 按登记时股数计量；`ex_price_adjustment` 明确为除权时每股原始价格的调整额。若登记到除权间拆股，两种单位不同，必须由协议提供正确数值，并核对其等于每登记股总分红除以期间累计拆股比例（相对/绝对工程容差 `1e-10 × max(1, 调整额)`）；不一致则拒绝。参考 mark 作事件调整，实际开盘/收盘始终读取原始价格，不对实际成交价再次复权。

## 不确定性与拒绝策略

税制仅接受 `tax_exempt`（扣税额必须为零）或 `declared_withholding`（显式每登记股扣税额）。在除权应收中扣一次，支付日不再扣；它不是按真实 A 股持有期、卖出日和税收追缴重建的税务系统。`total_cost` 仍为交易费用，事件税额另报 `declared_withholding`，已进入净权益，不能再次从收益扣除。

拆股 `fractional_policy` 目前只接受 `reject`。总股数、可售股数或任何未交收批次会产生非整数时失败，即使合计可整除也不擅自挪动交收资格；尚未提供残股现金替代规则。配股、并购换股等未知事件不忽略。

终止估值须提供金额和估值依据；零金额也保留显式权利与阶段审计。未到结算日不得把该金额放进现金。生效后不能重新成为候选资产；执行数据必须显式缺价，禁止按陈旧报价交易。其余退市/停牌持仓继续留账，不由名称或资产池退出推断终止处置。

初始历史账户是协议方声明，不是平台认证：系统检查阶段、权利金额、支付时间与存续证券的一致性，不能在没有登记日前成交历史时证明初始有权股数。默认新示例从明确现金状态开始，并从登记日生成可核对的全路径。

## 因果性与会计验收

本地策略上下文仅增加 `available_at <= decision_time` 的不可变事件对象，不传未来执行价格。执行器在目标绑定原决策状态并验证后，推进事件和真实账户；目标身份不换绑为未来状态。固定提交不能证明用户代码没有读取未来，证据仍披露这一限制。

每个事件分别记录现金、证券市值、应收变化、预期事件损益与会计残差。预期事件损益独立定义：登记、拆股和支付为零；除权为新增税后应收减旧持仓除权估值调整；终止为给定索赔价值减证券账面价值。

每日核对：`期末权益 - 期初权益 = 隔夜市场损益 + 日内市场损益 + 公司行为损益 - 交易费用`。事件税额已包含在公司行为损益。手算和残差门槛沿用 ADR 001，失败中止路径并保留 INVALID；精确会计差异不能解释为可微代理误差。

覆盖登记后卖出、除权后买入、扣税、延迟支付、支付前买入受阻、整数与非整数拆股、未交收批次、终止减记/延迟结算、同刻支付、未来事件扰动、旧版拒绝和冻结产物重算。软件回放仍固定 `SYNTHETIC_ONLY/DIAGNOSTIC_ONLY`，不升级真实市场效用资格；连续效用训练和独立代理差异仍是后续任务。
