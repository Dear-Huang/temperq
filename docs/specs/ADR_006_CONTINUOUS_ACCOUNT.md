# ADR 006：连续账户、动作时序与分段梯度

日期：2026-10-23。状态：N03 的账户/效用基础已实现；训练器、生产动作映射和完整阶段验收待完成。依据：[N03 SPEC](N03_UTILITY_TRAINING_SPEC.md)、[ADR 005](ADR_005_PREDICTION_ALLOCATION.md)。

## 问题和证据

N02 的意图代理按收盘已知权重变化计量，执行器按次日开盘实际权益和价格定量。即使 `w=h`，旧股数与开盘目标股数也可能不同；再叠加最低佣金，意图成本不能代表真实费用。将昨日目标作为实际账户、或仅优化相邻目标权重之差，均不能修复这个问题。

冻结案例的同成交费用分解为：实际 250.075836 元，成交代理 68.367685 元；最低佣金溢价 192.746076 元，代理额外计入冲击 11.037924 元，税率和滑点差为零。`192.746076 - 11.037924 = 181.708152`，解释了实际与成交代理的差额。它是给定成交的恒等分解，不是市场冲击模型校准结果。

## 决策

1. 新建 `portfolio.continuous` 的 CPU float64 Tensor 账户，持有数量、现金、参考估值、交收批次、登记权利与应收。状态推进保持计算图；仅诊断序列化和显式 `detach()` 停止梯度。初始账户来自现有版本契约，非空挂单继续拒绝。
2. 先计旧持仓隔夜，再按开盘权益将目标比例变成股数，先卖后买并支付费用，最后计日内估值和公司行为。资金约束使用含费用的可买金额；现金不能因费用透支。未知开盘不能伪造交易，缺价估值有审计提示。
3. `None` 动作明确保持股数，需要 `ContinuousIntent.hold_reason`；它与重新提交旧权重不同。该语义只属于内部训练/对照 API，不修改公开目标权重 schema 或把失败变成未声明现金回退。
4. `ContinuousConfig` 独立声明整数手、交收、市场成交限制、最低佣金与费用模型。`declared_execution` 计算比例费用/最低佣金及既有税费规则；`causal_linear` 将 N02 的已知方向系数应用到实际模拟成交；`none` 仅用于无费软件控制。不同模式是不同实验，不能根据收益更换后沿用原冻结计划。
5. 组合层仍复用 CVXPYlayers；不在账户内重写优化器。Tensor 账户独立实现交易与事件推进，不调用原始股数 Bench 的账户推进或费用求值函数；共享版本契约、事件计划和费率规则。整数模式必须对照独立账户。
6. 分红登记、除权确认应收、支付及终止索赔保留原时序。连续份额放松拆股后的整数性；整数模式仍拒绝分数持仓或交收批次。权利支付保持计算图，应收不提供提前买入现金。
7. `portfolio.episode.run_episode` 按协议顺序推进；策略只收到当前账户、当前资产池、已知事件和执行时间。资产由当前资格与存续持仓构建，不取未来资产池并集。策略上下文不含未来成交行；任意本地策略代码的信息访问仍不由平台认证。
8. `training.utility.net_utility` 使用已扣费权益的平均对数增长与简单净收益总体方差（ddof=0），不再次扣费。非正权益、非有限输入或动作违规直接失败。
9. `recipes.estimate_tensors` 复用相同可见历史估计，风险矩阵与历史成交额固定；资本/流动性系数保留对当前权益的梯度。审计中的标量权益只用于记录，不替代计算图中的状态。

## 梯度和验收边界

连续份额下，数量、实际换手、现金、费用和后续漂移状态参与反传。最小值/最大值、零交易、最低佣金和活跃约束产生分段或不连续映射；市场停牌/限价等为环境揭示的硬门，整数 `floor` 的局部导数为零。没有 straight-through、裁剪负权重再归一化、或将 HiGHS 投影梯度伪装成求解器梯度。

光滑路径分别检查账户资金约束的导数、带账户反馈的多日效用导数、CVXPYlayers 参数到多日效用的导数；边界和整数模式单列。当前测试不等于已经验证 GRU 参数、完整训练循环和生产映射的梯度。

公开原始目标校验仍严格拒绝负权重。N03 在接训练器前，还需为求解器边界解确定显式训练/生产动作关系并做消融，保留所有失败。不能为让训练跑通而隐藏现有边界失败。

## 对照与后续

`scripts/run_continuous_audit.py` 在同一冻结初始账户与目标序列下，报告无费、比例费用、最低佣金、整数手、交收、成交限制、因果线性费用和保持股数八种模式。重算原决策状态下的因果风险/成本配方；不根据松弛账户的新状态重新生成模型目标，因此这些是固定动作诊断，不是闭环策略优胜比较。不同模式还会改变后续成交/资金，模式之间的差异不能相加当作绩效归因。

冻结 29 日案例中整数完整模式的数量与交收差异为零，权益/现金最大差异约 `8.15e-10` 元，费用差异约 `8.88e-16` 元。分数份额加最低佣金费用约 528.47 元，高于整数模式 250.08 元，表明最低佣金对微小交易与离散执行敏感；这是仍需明确处理的代理偏差。

运行方式及最终验证记录见 [连续账户说明](../CONTINUOUS_ACCOUNT.md) 和 [验证记录](../VALIDATION.md)。后续继续 N03 的生产映射、GRU 连续效用训练、新配置/CLI/worker、checkpoint 与失败归档，以及独立账户反馈比较；N04/N05 与真实经济门槛未完成。
