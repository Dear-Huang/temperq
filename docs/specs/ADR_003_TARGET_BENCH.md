# ADR 003：独立目标持仓回放入口

日期：2026-10-23。状态：实施中，尚未通过完整 M2。

接续：本 ADR 以下无公司行为限制描述 v1 入口；新增 v2 的应收、分红/拆股及终止账本见 [ADR 004](ADR_004_ACCOUNT_LIFECYCLE.md)，不重新解释 v1。

首个入口单独接收 `target_submission_v1`，每个声明决策必须有 `target_weights_v1` 或显式 `decision_failure_v1`。目标绑定冻结协议、实际状态、任务、快照、决策资产池和执行时间；缺失、重复、过期、身份冲突直接失败。不会把目标当作已成交持仓或旧分数。

冻结协议声明初始原始股数/现金、完整会话时点、决策可选资产、实际执行数据、费用与风险限制。回放先构造决策时实际状态，再验证目标，执行时才读取行情；现有持仓继续留在账户，退出候选池禁止新增买入。只支持开盘 IOC：未成交当次到期并留审计，禁止已有跨日挂单，不暗中丢弃。

新增纯数据 CLI 评价与重算验证，以及本地受信任 Python 策略回调 API；回调仅接收状态/决策约束，公开网站不执行提交代码。协议和提交原文随结果冻结，输入身份、实现身份、逐日目标/实际权重、成交、费用、状态和净权益可独立重算。

公司行为是完整 M2 的独立门槛。第一步仅接受显式空事件集，遇到非空公司行为明确拒绝，不把不支持的事件忽略为零；所有结果至多为诊断或合成软件证据。分红登记/除权/支付的应收资产、整数拆股、税费和终止估值需要状态版本升级，不能把现金分红直接当成当日行情收益，也不能在除权日至支付日让权益凭空消失。

工程与经济证据分开：完整回放和重算通过只证明该冻结数据路径的软件行为，不能证明真实 A 股可成交性、数据授权、容量、时点覆盖或经济增益。完整 M2 仍须公司行为与账户生命周期验收；M3 还须独立的训练代理及逐日差异核对。
