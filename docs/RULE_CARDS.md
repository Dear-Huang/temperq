# 规则卡与本地 AI 协作

规则卡是数据文件，不执行 Python。工作台的点选编辑、导出和导入共用
`rule_card_v1`；导入后先查看中文复述和差异，确认后进入新草稿，原账户不变。

```powershell
temperq rule validate examples/rule_card_v1.json --json
```

退出码 0 表示格式和规则合法，1 表示错误；校验只读，不创建策略或检验记录，
不证明数据齐全、规则有效或收益优势。命令不会调用模型服务。

## 格式

顶层且仅有 `schema`、`id`、`name`、`rules`。示例见
[rule_card_v1.json](../examples/rule_card_v1.json)。每条规则包含：

| 字段 | 约束 |
| --- | --- |
| `id` | 小写字母开头，其后小写字母、数字或下划线，最长 64 字符，同卡不重复 |
| `field` | `open`、`high`、`low`、`close`、`amount`、`volume` |
| `operator` | 下表列出的操作符 |
| `window` | 1–504 的整数；波动窗口至少 2 |
| `value` | 双均线的长窗口、均值倍数或收益阈值；其他操作为 0 |
| `weight` | −10 至 10 的非零有限数；连续值先按当日百分位归一化 |
| `required` | 布尔值；仅条件类型允许必须满足 |
| `origin` | `template`、`user`、`imported`；文件导入强制改为 `imported` |
| `description` | 可省略；如提供，必须与平台生成的中文复述完全一致 |

| 操作符 | 定义 |
| --- | --- |
| `above_mean` | 当前值高于包含当日的 N 日均值，0/1 |
| `mean_above_mean` | N 日均值高于长窗口均值，长窗口为整数且大于 N，0/1 |
| `return` | N 日价格收益；负权重表示反转，连续排名 |
| `low_volatility` | N 日单日收益样本标准差取负，连续排名 |
| `return_above` | N 日价格收益大于 `value`，如 0.05 表示 5%，0/1 |
| `above_mean_ratio` | 当前值大于 N 日均值乘 `value`；倍数范围 0.1–10，0/1 |

收益、波动和双均线仅接受价格字段。价格乘当日复权因子计算历史相对变化；
执行仍用原价。成交量需要真正的 `volume` 字段，不用成交额换算。缺失和窗口
不足保留为未知；连续输入未知的运行日受阻，不当作条件不成立。没有股票满足
完整条件时可以持有现金，不复制旧排名。已有持仓的成交受阻仍由统一账本处理。

候选需要至少 60 个有效交易日历史；规则需要更长窗口时相应提高，例如 100 日
收益波动需要 101 个价格观测。这个要求会显示并冻结，修改窗口引起的候选范围
变化单独列出。修改同一策略会沿用规则检验系列，失败的检验也计入尝试次数。

同一 JSON 中不接受额外字段、表达式代码、未来窗口、未知格式或重复键。
上限为 64 KB、20 条规则。费用、账户、自动运行与市场时点不属于规则卡格式。

## 使用路径

在“从你的经验开始”选择模板，修改条件后保存并查看模型检验，再配置账户规则。
外部 AI 可以根据此格式产生文件，用户在模板页导入并确认；平台不连接 AI 服务。
所有历史检验都保留尝试，来源不改变检验纪律。查看结果属于开发分析，统计不确定
可进入明确标记的纸面观察，不能据此认定未来收益。

规则检验页可下载 Markdown / JSON 成绩卡；导出采用字段白名单，不带账户初值、
持仓明细、token 或数据路径。“导出冻结配置”和“成绩卡”是不同文件，前者含个人配置。
